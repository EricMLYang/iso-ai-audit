## 3. 法規對應

| 法規 | 適用情形 | 政策對應 |
|---|---|---|
| **人工智慧基本法**（2026/01/14 公布施行；中央主管機關：國科會） | 七大原則：永續發展與福祉、人類自主、隱私保護與資料治理、資安與安全、透明與可解釋、公平與不歧視、問責 | POL-001 §四 逐條對應七大原則 |
| **個人資料保護法** | 心率、血氧、睡眠等屬健康相關資料，以特種個資標準從嚴保護；手機連動資料含第三人個資 | POL-001 §四-3、POL-002 §五 |
| **資通安全管理法**（2025 修正） | 本公司**非**公務機關或特定非公務機關（關鍵基礎設施、公營事業、政府捐助財團法人），不直接適用。採「參照遵循」：資安長設置、事件通報時限、資安專職人員；若承接政府委外案，依契約遵循 | POL-002 §三、§六 |
| GDPR／EU AI Act | 產品銷售至歐盟（作業 4 範圍） | POL-001 §五、POL-002 §五 |

## 4. 「宣告式政策」vs「可被查證的領導」

| 只是宣告 ❌ | 可查證的領導 ✅ | 本範例做法 |
|---|---|---|
| 「重視 AI 倫理」 | 原則對應到具體控制與量測 | POL-001 §四 每項原則列「落實方式」與 KPI |
| 政策由 AIMS 小組發布 | 由董事會／最高管理階層核定並有紀錄 | POL-001 §九 董事會核定日期、會議紀錄編號 |
| 「提供必要資源」 | 預算、人力有決議紀錄 | FRM-005-01 §三 資源決策證據 |
| 組織圖上有資安長 | 任命書、職務說明、RACI | FRM-005-01 §一、§二 |
| 政策放在內網 | 對內訓練完成率、對外公開網址 | POL-001 §八 溝通方式 |
