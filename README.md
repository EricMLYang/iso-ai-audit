## 用 AI 助理協助時

本 repo 根目錄的 `CLAUDE.md` 會讓 Claude Code 自動知道課程背景、案例公司、命名規則與版權界線。建議的用法：

- 「依 `02_作業/作業_單元6` 的題目，延續智腕科技情境，產出風險評鑑表草稿」
- 「用條款 4 的稽核角度，檢查 `作業範例_穿戴式裝置/` 裡的追溯鏈缺了什麼」
- 「從 `03_考試準備/練習題.md` 隨機出 5 題考我，答完再給解析」

> ⚠️ 課程規定：不得把 ISO/IEC 標準原文餵給 AI；考試時禁止使用 AI。詳見 [使用原則](00_課程導覽/使用原則.md)。
