# 課程 AIMS 文件化資訊架構與本 repo 編號對照

> 對應課程資源：課程參引〈AIMS 文件化資訊架構清單〉（案例研討；單元 4～10 作業都用得到）。
> 本檔只摘要架構規則、各章文件 **群組**，並對照本 repo 已用的編號。完整清單請看課程頁，不在此複製。
> 用途：寫後續單元作業時，先查這裡決定編號，避免撞號。

## 1. 文件層級與類型代碼

| 層級 | 代碼 | 類型 |
|---|---|---|
| L1 | MAN | 手冊（總綱） |
| L1 | POL | 政策 |
| L2 | PRO | 程序書 |
| L3 | SOP | 作業指導書 |
| L4 | FRM | 表單 |
| L4 | REC | 紀錄 |
| L4 | MTX | 矩陣（角色、控制、責任對照） |
| L4 | REG | 清冊、登錄（法規、系統、資產、供應商） |
| L4 | RPT | 報告 |
| L4 | DAS | 儀表板 |

**編碼規則**：`AIMS-類型-主序號(NNN)-附屬序號(YY)`。表單跟著母程序的主序號，例如 PRO-009 的表單是 FRM-009-01、02……

| 10 改進 | **不符合與矯正措施程序**（登錄、**根本原因分析**、矯正計畫、**有效性驗證**、結案、改善機會清冊） | A.2、A.6、A.7、A.10 |

**看得出的設計重點**（寫作業時可以學）：
- 課程架構把 **生成式 AI、Prompt、RAG** 都納入受控對象，各有登錄、測試、變更、監測表單。
- **人工監督** 獨立成政策、SOP、四張紀錄表（覆核、異常升級、人工接管、高風險檢查）。
- 第 9 章把 **稽核方案** 與 **內部稽核** 分成兩支程序，正好對應 19011 第 5 章與第 6 章。
- 課程頁自己也註明 **原始清單有編號重複**，有待治理決議。
