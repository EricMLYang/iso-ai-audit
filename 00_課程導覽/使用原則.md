# 使用原則（版權與 AI 使用）

課程首頁有一份免責與版權聲明。以下是我們整理出、跟這個 repo 直接相關的重點（用自己的話摘要，完整內容以課程頁為準）：

## 課程教材

- 教材、講義、簡報、範本、案例、題目等，僅供 **已註冊學員個人學習** 使用。
- 不得複製給他人、公開上傳或分享、改作成其他課程或商業素材。

## ISO/IEC 標準

- 標準著作權屬 ISO/IEC 等權利人；正式要求以合法取得的標準文件為準。
- 不得重製標準的完整內容、大量摘錄、表格或附錄。
- **不得把未經授權的標準原文輸入 AI 工具**。

## 這個 repo 因此採取的做法

本 repo 是 **public**，所以：

| ✅ 可以放 | ❌ 不要放 |
|---|---|
| 用自己的話寫的觀念解說 | 課程頁面、講義的逐字複製 |
| 條款編號與標題、自製對照表 | 標準條文原文或大段翻譯 |
| 原創範例（虛構的智腕科技）、作業成品 | 課程提供的案例公司文件原檔 |
| 原創練習題 | 課程考題或題庫 |
| 指向課程資源的名稱（「參見單元 4〈A.6〉」） | 下載的課程 PDF、簡報 |

## 考試

考試為開卷，但 **禁止上網搜尋答案、禁止使用 AI（例如 ChatGPT）協助作答**。AI 只用在考前複習。
