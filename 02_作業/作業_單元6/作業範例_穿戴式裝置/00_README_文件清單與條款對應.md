## 4. 全景 → 風險 → 處理 → SoA → 控制 → 目標 稽核軌跡（範例）

```
FRM-001-01 社會與倫理議題「不同膚色光學心率準確度差異」
  → FRM-001-02 IP-005「不同族群準確度一致」
    → FRM-010-02 SN-05 → SR-07「分組誤差差異 ≤ 5%」
      → AIA-2026-001 IM-03「深膚色敏感度 84.2%，差 8.9%」（極高）
        → PRO-002 RC-006（固有 4/4 極高 → 處理後 2/4 高）
          → 處理：A3 擴充資料、A4「無法判讀」不顯示正常、揭露限制
            → SoA：A.7.4 資料品質、A.6.2.4 查證確認、A.5.4（實施中）
              → AI 目標（A13）：2027 所有健康模型分組差異 ≤ 5%（FRM-003-01）
                → 殘餘風險：委員會接受至 2027/06（C5，FRM-002-03）
                  → 有效性：A3 完成後分組重測報告（第 7 層證據）
```

## 5. 範本補強重點（作業要求「程序書範本可能有所不足」）

| 範本 | 不足 | 本範例補強 |
|---|---|---|
| 風險程序 | L、C 只有「極低～極高」字樣，不同人評分不一致 | 每級給頻率／比例與五個後果面向的具體描述；評分須附依據；校準機制 |
| 風險程序 | L×C 會稀釋「低機率、嚴重後果」 | 後果下限規則：健康、個資、法規 C ≥ 4 至少為「高」 |
| 風險程序 | 沒有 SoA 與附錄 A 比對步驟（§6.1.3 核心要求） | §10.2 四步驟與 SoA 欄位 |
| 風險程序 | 未說明與衝擊評鑑、生命週期的連結 | §9.3、§11.2 |
| 風險程序 | 無法判斷風險管理做到哪一層 | §11.3 七層次證據標記 |
| 衝擊程序 | 混入「組織影響」，與風險評鑑重疊 | 聚焦個人、群體、社會；組織面交給 PRO-002 |
| 衝擊程序 | 缺 42005 §5.1、§5.3、§5.4 時機、§5.5 範圍、§5.7 門檻、§5.10 對外報告、§5.12 審查產出 | 見 PRO-006 §0 對照表 |
| 附錄 E 範本 | 只到故障與誤用，沒有處理措施、門檻比對與核准 | AIA §8～§9 |
