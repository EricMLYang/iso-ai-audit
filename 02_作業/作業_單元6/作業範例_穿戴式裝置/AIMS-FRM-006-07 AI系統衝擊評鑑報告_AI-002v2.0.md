## 0. 評鑑緣由與觸發（E.2.1）

**情境**：AI 開發團隊提案將 AI-002 健康風險預警由 v1.3（以心率閾值與 HRV 規則加小型分類器判斷「心率異常偏高／偏低」）升級為 v2.0，新增 **「心律不規則提示」**：以手錶光學心率（PPG）訊號，經深度學習模型判斷一段時間內的脈搏節律是否持續不規則，並提醒使用者就醫確認。預計同時：

- 使用新蒐集的使用者資料與合作醫院研究資料重新訓練；
- 支援新一代錶款 WristAI 2（新光學感測器）；
- 2027 Q2 隨 WristAI 2 於台灣上市，2027 Q3 進入歐盟（德、法、荷）。

**分流結果（FRM-006-06，2026/10/20，王小明審查）**

| 分流問題 | 結果 | 說明 |
|---|---|---|
| Q1 敏感用途 | **是** | S1 疾病相關提示；S3 主要受益族群為 50 歲以上與長者 |
| Q2 受限制用途 | **是** | R1 健康資料訓練；R2 跨境；R3 可能構成醫療用途宣稱 |
| Q3 新增特種個資類型 | 是 | 新增 PPG 原始波形上傳（v1.3 僅上傳摘要） |
| Q4 受影響 > 1 萬人 | 是 | 現有 WristAI 使用者約 18 萬人 |
| Q5 影響健康行為 | 是 | 直接影響是否就醫 |
| **結論** | **完整 AIA** | 觸發 PRO-006 §8.2 T1（預期用途延伸）、T3（資料、模型）、T4（新感測器）、T5（新市場） |

本 AIA 識別 v2.0 對個人、群體與社會的可合理預見衝擊；判定其屬 **敏感用途且含受限制用途**，需 AI 治理委員會審議，最終上線由陳總經理核准（因存在「極高」衝擊項目，見第 8 段）。

### 1.2 系統描述（E.2.2.2，42005 §6.3.1）

手錶以光學感測器持續量測脈搏；當使用者靜止（加速度計判定）時，擷取 60 秒 PPG 片段，經 **手錶端** 的訊號品質模型篩選，再由 **手錶端** 節律分類模型判斷「規則／不規則／無法判讀」。若 **連續 3 個 30 分鐘視窗** 中有足夠片段被判為不規則，手機 App 推送提示，內容包含觸發時段、判讀依據摘要與「此非醫療診斷，請諮詢醫師」，並可匯出 PDF 給醫師參考。片段與判讀結果同步至雲端供使用者查看歷史；**原始 PPG 波形僅在使用者另行同意「協助改善模型」時上傳**。

### 1.4 目的（E.2.2.4，§6.3.3）

| 項目 | 內容 |
|---|---|
| 最終使用者 | WristAI 使用者，特別是 50 歲以上、有心血管疾病家族史者 |
| 滿足的需求 | 許多心律不規則是間歇且無症狀的，就診時不一定被抓到；長時間配戴的手錶可提高「被注意到、進而就醫確認」的機會 |
| 價值主張 | 提醒而非診斷：協助使用者把握就醫時機，並提供紀錄給醫師參考 |
| 權衡取捨 | 提高敏感度 → 誤報增加、焦慮與不必要就醫；提高特異度 → 漏報增加。採「寧可提示就醫、但以連續視窗與每日上限控制頻率」；放棄在「無法判讀」時給出結果，以避免假安心 |

## 3. 演算法與模型資訊（E.2.4，§6.5）

### 3.1 演算法（表 E.12）

| 項目 | 內容 |
|---|---|
| 適用性 | 節律判讀需從時序波形中學習間隔變異的模式，規則式 HRV 閾值在 v1.3 回溯測試中敏感度僅 71%，不足以支持 U1 |
| 來源 | 以公開文獻常見的 1D 卷積＋注意力機制時序分類架構為基礎，自行實作，未使用外部預訓練權重 |
| 有效性 | 同類架構於學術文獻有多篇驗證；本公司另以 D2、D3 做內外部驗證 |
| 先前應用 | 公司首次用於節律判讀；同業同類功能已上市，部分市場以醫療器材軟體取得許可（見 IM-07） |
| 資料要求 | 每片段 60 秒、25 Hz 以上取樣、SQI 合格 |
| 對不良結果的易感性 | 對動作偽影、配戴鬆緊、膚色（光吸收）、刺青敏感；可能學到「低訊號品質＝不規則」的偽相關 → 以 SQI 前置模型與對照實驗檢查 |

### 3.2 模型（表 E.13 摘要）

| 項目 | 內容 |
|---|---|
| a) 開發資料與演算法 | D1 訓練＋確認；D2 測試（真值來自 ECG）；D3 外部測試 |
