## 4. 「形式完整」vs「實際可用」

| 只是形式完整 ❌ | 實際可用、能當證據 ✅ | 本範例做法 |
|---|---|---|
| 有文件編碼規則 | 編號能讓人從表單找到母程序；舊號不重用 | PRO-009 §6.2；F1、F2 |
| 文件有核准欄 | 核准後的每次修改都有升版與紀錄 | F3、F4 |
| 文件清冊列出已寫好的文件 | 也列出「被引用但還沒建立」的文件，有負責人與期限 | FRM-009-01 §1.4；F5 |
| 「紀錄依規定保存」 | 期限有起算點；含個資的紀錄到期真的刪除 | PRO-009 §13 |
| KPI 寫「文件更新完成率」 | 抽查現場實際使用的版本 | PRO-009 §15 |
