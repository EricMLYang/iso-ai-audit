```

├── 作業_N_<主題>.md             ← 題目、條件、參考（從 _模板 複製）
├── 參考文件格式/                 ← 課程或自己整理的空白範本（選用）
```

## 案例公司：智腕科技（虛構）

所有作業延續同一家公司，讓追溯鏈可以跨單元串起來。

| 項目 | 內容 |
|---|---|
| 產品 | AI 智慧手錶 WristAI ＋ 手機 App ＋ 雲端服務 |
| AI 角色 | AI 開發者、AI 提供者（語音助理若用第三方 LLM，該部分為 AI 使用者） |
| AI 功能 | 心率、睡眠、血氧分析，運動辨識，健康風險預警，個人化建議，語音助理 |
| 敏感點 | 健康相關敏感個資；手機連動存取行事曆、通知、聯絡人、位置 |
| 法規 | 人工智慧基本法、個資法、資通安全管理法；外銷考慮 GDPR |

## 寫作業的自我檢查（講師評分精神）

- [ ] 每項主張都有 **編號**，且被下游文件引用（可追溯）
- [ ] 每個要求都有 **驗證方式**（測試、紀錄、量測）
- [ ] 有 **負責人、核准、版本、日期、審查週期／觸發條件**
- [ ] 有 **條款對應矩陣**（00_README）讓稽核員一眼找到證據
- [ ] 範圍與排除有理由，且與資料流、供應商依存一致
- [ ] 用稽核員角度自問：這份文件能回答「誰、依什麼、證據在哪」嗎？
