# 詞彙速查

> 白話定義，自行整理。正式定義請查 ISO/IEC 42001 §3、ISO/IEC 22989、ISO 31073、ISO 19011 §3。

## AI 與 AIMS

| 中文 | 英文 | 白話 |
|---|---|---|
| AI 管理系統 | AIMS, AI management system | 組織管理 AI 相關政策、目標、流程的管理系統 |
| AI 系統 | AI system | 針對人定的目標產生預測、建議、決策、內容等輸出的工程系統 |
| 預期目的／用途 | intended purpose / use | AI 系統被設計來做什麼、在什麼條件下用 |
| AI 利害關係人角色 | AI stakeholder roles | 提供者、生產者、客戶、夥伴、主體、主管機關（22989） |
| AI 主體 | AI subject | 資料被處理或受 AI 決策影響的人 |
| AI 系統衝擊評鑑 | AI system impact assessment | 評估 AI 系統對個人、群體、社會可能的後果（42005） |
| 適用性聲明 | SoA, statement of applicability | 列出附錄 A 控制是否適用、理由與實施狀態 |
| 資料漂移 | data drift | 營運資料分布與訓練資料不同，導致表現下降 |
| 持續確認 | continuous validation | 營運中持續確認模型仍符合需求（5338 6.4.14） |
| 可解釋性 | explainability | 能以人能理解的方式說明 AI 輸出的原因 |
| 透明性 | transparency | 對相關方揭露 AI 系統的適當資訊 |

## 管理系統

| 中文 | 英文 | 白話 |
|---|---|---|
| 組織情境／組織全景 | context of the organization | 影響組織達成目標的內外部議題 |
| 關注方／利害關係人 | interested party / stakeholder | 會影響、被影響、或自認被影響的人或組織 |
| 最高管理階層 | top management | 在最高層級指揮和管控組織的人 |
| 文件化資訊 | documented information | 須管制與維持的資訊（文件與紀錄） |
| 有效性 | effectiveness | 規劃的活動被實現、規劃結果被達成的程度 |
| 符合性 | conformity | 滿足要求 |
| 不符合 | nonconformity | 未滿足要求 |
| 修正 | correction | 消除已發現的不符合 |
| 矯正措施 | corrective action | 消除不符合原因、防止再發 |
| 持續改善 | continual improvement | 為提升績效而重複進行的活動 |
| 委外 | outsource | 由外部組織執行組織的部分功能或流程 |

## 風險

| 中文 | 英文 | 白話 |
|---|---|---|
| 風險 | risk | 不確定性對目標的影響 |
| 風險準則 | risk criteria | 評估風險重大性的參照標準 |
| 風險評鑑 | risk assessment | 風險識別 + 風險分析 + 風險評估 |
| 風險處理 | risk treatment | 修改風險的過程 |
| 風險偏好 | risk appetite | 願意追求或保留的風險量 |
| 殘餘風險 | residual risk | 處理後剩下的風險 |
| 風險擁有者 | risk owner | 有權責管理該風險的人 |

## 稽核與驗證

| 中文 | 英文 | 白話 |
|---|---|---|
| 稽核 | audit | 有系統、獨立、文件化地取得證據並客觀評估符合準則程度的過程 |
| 稽核方案 | audit programme | 一段期間內一系列稽核的安排 |
| 稽核計畫 | audit plan | 單一次稽核的活動安排 |
| 稽核準則 | audit criteria | 比對用的要求 |
| 稽核證據 | audit evidence | 與準則相關、可查證的紀錄或資訊 |
| 稽核發現 | audit findings | 證據對照準則的評估結果 |
| 稽核結論 | audit conclusion | 考量目標與所有發現後的結果 |
| 稽核委託方 | audit client | 要求稽核的組織或人 |
| 受稽方 | auditee | 被稽核的組織 |
| 技術專家 | technical expert | 提供特定知識給稽核組，但不是稽核員 |
| 觀察員 | observer | 陪同稽核組但不參與稽核 |
| 嚮導 | guide | 受稽方指派協助稽核組的人 |
| 驗證 | certification | 第三方證明管理系統符合要求 |
| 認證 | accreditation | 權責機構證明驗證機構有能力（認證「驗證機構」） |

> 易混：**驗證（certification）** 是驗證機構發證給組織；**認證（accreditation）** 是認證機構（如 TAF）認可驗證機構。
