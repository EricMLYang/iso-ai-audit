# 稽核與驗證：ISO 19011、ISO/IEC 17021-1、ISO/IEC 42006

> 對應課程單元 3、11–14，考試單元 2–5。自行整理。

## 1. 三份標準的分工

| 標準 | 給誰用 | 性質 |
|---|---|---|
| ISO 19011 | 任何做管理系統稽核的人（內稽、供應商稽核、驗證） | 指引 |
| ISO/IEC 17021-1 | 管理系統 **驗證機構** | 要求（驗證機構被認證的依據） |
| ISO/IEC 42006 | 做 **AIMS 驗證** 的驗證機構（在 17021-1 之上加 AI 特定要求，如稽核員 AI 能力、稽核時間） | 要求 |

## 2. 稽核類型

| 類型 | 誰稽核誰 | 例 |
|---|---|---|
| 第一方稽核 | 組織稽核自己（內部稽核） | 42001 §9.2 |
| 第二方稽核 | 客戶稽核供應商（或代表客戶的人） | 品牌商稽核 AI 標註廠 |
| 第三方稽核 | 獨立機構稽核（驗證、法規） | 驗證機構做 42001 驗證 |

- **結合稽核（combined audit）**：同時稽核兩套以上管理系統（例如 27001 + 42001）。
- **聯合稽核（joint audit）**：兩個以上稽核組織一起稽核同一受稽方。

## 3. 七大稽核原則（19011 §4）

| 原則 | 白話 |
|---|---|
| 1. 誠正（integrity） | 誠實、勤勉、負責、守法、公正 — 專業的基礎 |
| 2. 公正呈現（fair presentation） | 如實、準確報告，包括未解決的歧見 |
| 3. 適切的專業注意（due professional care） | 依稽核重要性與委託方信任，審慎判斷 |
| 4. 保密（confidentiality） | 資訊安全，不不當使用稽核取得的資訊 |
| 5. 獨立性（independence） | 不稽核自己的工作，無利益衝突，結論客觀 |
| 6. 證據導向（evidence-based approach） | 結論基於可查證的證據，通常是抽樣 |
| 7. 風險導向（risk-based approach） | 稽核規劃、執行、報告都考量風險與機會，聚焦重要事項 |

> 記憶：**誠、公、專、密、獨、證、險**。

## 4. 從證據到結論（排序題常考）

```
資訊來源 → 用適當抽樣蒐集與查證 → 稽核證據 → 對照稽核準則評估 → 稽核發現 → 審查 → 稽核結論
```

| 詞 | 定義（白話） |
|---|---|
| 稽核準則（audit criteria） | 拿來比較的參照：標準要求、政策、程序、法規、合約 |
| 稽核證據（audit evidence） | 與準則有關、**可查證** 的紀錄、事實陳述或其他資訊 |
| 稽核發現（audit findings） | 證據對照準則後的評估結果：**符合／不符合**，也可能是改善機會 |
| 稽核結論（audit conclusion） | 考量稽核目標與所有發現後的整體結果 |
| 稽核範圍（audit scope） | 稽核的界限：地點、單位、活動、流程、期間 |
| 稽核目標（audit objectives） | 這次稽核要達成什麼 |

## 5. 稽核方案 vs 稽核計畫

| | 稽核方案（audit programme） | 稽核計畫（audit plan） |
|---|---|---|
| 範圍 | 一段期間內的 **一系列** 稽核安排 | **單一次** 稽核的活動與安排 |
| 誰負責 | 稽核方案管理者 | 稽核組長 |
| 內容 | 目標、範圍、頻率、資源、方法、風險、稽核組遴選 | 目標、範圍、準則、日期地點、時程、方法、角色、抽樣 |
| 19011 | §5 | §6.3.2 |

**稽核方案管理（19011 §5）**：建立方案目標 → 判定方案的風險與機會 → 建立方案（角色責任、能力、範圍、資源）→ 實施（定個別稽核目標範圍準則、選方法、遴選稽核組、指派組長、管理結果與紀錄）→ 監督 → 審查與改善。

**稽核方法**：現場／遠端 × 有人員互動（訪談、陪同觀察）／無人員互動（文件審查、系統資料分析）。

## 6. 執行稽核（19011 §6）

| 步驟 | 重點 |
|---|---|
| 6.2 啟動稽核 | 與受稽方建立聯繫、判定稽核可行性 |
| 6.3 準備稽核活動 | 審查文件化資訊、規劃稽核（風險導向）、分派工作、準備工作文件（檢查表、抽樣計畫） |
| 6.4 執行稽核活動 | 起始會議 → 稽核中溝通 → 蒐集與查證資訊 → 產生稽核發現 → 決定稽核結論 → **結束會議**（6.4.10） |
| 6.5 撰寫與發送報告 | 報告內容、發送對象 |
| 6.6 完成稽核 | 計畫活動都完成或依約結束 |
| 6.7 稽核跟催 | 確認矯正措施完成與有效（可能在下次稽核驗證） |

**蒐集證據的方法**：訪談、觀察、文件與紀錄審查、系統操作或測試、抽樣。

## 7. 驗證稽核流程（17021-1）

```
申請 → 申請審查（可行性、能力、稽核時間）→ 第一階段 → 第二階段 → 驗證決定 → 發證（3 年）
     → 監督稽核（每年至少一次，首次在驗證決定後 12 個月內）→ 重新驗證（證書到期前）
```

| | 第一階段（Stage 1） | 第二階段（Stage 2） |
|---|---|---|
| 目的 | 文件審查與準備度評估：範圍、文件、場所、對標準的理解、是否已做內稽與管審、第二階段規劃資訊 | 評估管理系統 **實施與有效性**（現場） |
| 課程對應 | 單元 4–10「第一階段文件審查稽核軌跡」 | 單元 13 現場演練 |

## 8. 不符合分級與寫法

| | 主要不符合（major） | 次要不符合（minor） |
|---|---|---|
| 意義 | 影響管理系統達成預期結果的能力（例如整條要求未實施、系統性失效、嚴重疑慮產品／服務） | 不影響達成預期結果能力的單一或偶發失效 |
| 驗證影響 | 須在發證前驗證修正與矯正措施 | 須接受矯正措施計畫，下次稽核驗證 |

**不符合事項陳述三要素**：
1. **要求**（違反哪個準則：條款／程序）
2. **客觀證據**（看到了什麼：文件編號、紀錄、日期、受訪者職稱）
3. **不符合陳述**（哪裡沒做到）

> 例：「42001 §4.3 要求範圍考量與外部組織的介面與依存。智腕科技範圍聲明 AIMS-FRM-001-05 v1.0 未列入 AWS 東京區推論服務，但現場確認健康風險預警模型於該服務執行（雲端主控台截圖 2026-10-12）。範圍未涵蓋 AI 系統的實際執行環境。」

## 9. 稽核員能力與行為

- 能力 = 知識 + 技能 + 個人行為；42006 對 AIMS 稽核員額外要求 AI 技術、AI 風險、資料、生命週期等知識。
- 個人行為：合乎倫理、心胸開放、圓融、善於觀察、敏銳、多才、堅持、果斷、自立、堅毅、開放改善、文化敏感、合作。
- 稽核組長：規劃、協調稽核組、主持會議、彙整發現、形成結論、撰寫報告、解決爭議。

## 10. 情境題判斷原則

| 情境 | 正確方向 |
|---|---|
| 受稽方拒絕提供紀錄 | 記錄情況，報告稽核組長；可能影響稽核目標，需溝通委託方與受稽方 |
| 受稽方要你建議怎麼改 | 不提供顧問服務；可說明要求的意圖 |
| 只有口頭說明沒有紀錄 | 嘗試以其他來源查證；無法查證不可當證據 |
| 發現範圍外但重大的問題 | 告知稽核組長，必要時與委託方／受稽方溝通 |
| 時間不夠完成計畫 | 告知組長，調整計畫並與受稽方溝通 |
| 與受稽方對發現有歧見 | 嘗試解決；未解決的歧見記錄在報告中 |
