# ISO 31073:2022 — 風險管理詞彙：易混辨析（讀書筆記）

> 對應課程資源：課程參引〈ISO 31073 詞彙〉（單元 2、單元 6 必看）。31073:2022 取代 ISO Guide 73:2009。
> 自己的話整理，不是定義原文。重點放在 **考試會拿來做配對題、排序題的成對概念**。

## 0. 先記「風險管理過程」的順序（排序題）

溝通與諮詢 ＋ 建立全景 → **風險評鑑**（鑑別 → 分析 → 評估）→ 風險處理 → 監督與審查 ＋ 紀錄與報告

- 「風險評鑑（assessment）」是 **總稱**，包含鑑別（identification）、分析（analysis）、評估（evaluation）三步。
- 溝通與諮詢、監督與審查是 **貫穿全程** 的，不是某一步之後才做。

## 1. 風險的組成

| 詞 | 白話 |
|---|---|
| 風險（risk） | 不確定性對目標的影響；影響可正可負，可帶來機會與威脅 |
| 目標（objective） | 要達成的結果；可分策略、戰術、營運層級 |
| 不確定性（uncertainty） | 對事件、後果或可能性的 **資訊不足**，即使只是部分不足；是風險的根源 |
| 風險來源（risk source） | 本身或組合起來 **可能引發風險** 的要素；可有形或無形 |
| 事件（event） | 某組情況的發生或改變；可能預期會發生卻沒發生；事件本身也可以是風險來源 |
| 後果（consequence） | 事件對目標的結果；可直接或間接，且會 **連鎖或累積擴大** |
| 可能性（likelihood） | 某事發生的機會，可定性或定量；比「機率」意義更廣 |
| 機率（probability） | 0 到 1 的數值 |
| 頻率（frequency） | 單位時間內的事件數 |
| 危害（hazard） | 潛在 **傷害** 的來源；可以是風險來源 |
| 威脅（threat） | 潛在的危險或傷害來源；對一方是威脅，對另一方可能是機會 |
| 脆弱性（vulnerability） | 某事物的 **內在特性**，使它容易受某風險來源影響 |
| 暴露（exposure） | 組織或關注方受某事件影響的程度 |
| 機會（opportunity） | 預期對目標有利的情況組合；**抓或不抓機會都是風險來源** |
| 風險驅動因子（risk driver） | 對風險有重大影響的因素 |

**風險描述** 通常包含四要素：**來源、事件、原因、後果**。

### 易混：危害 vs 威脅 vs 脆弱性

- 危害：會造成傷害的東西，常用在人身安全，例如手錶電池過熱。
- 威脅：可能的負面來源，常用在資安，例如駭客。
- 脆弱性：自身弱點，例如 App API 沒有速率限制。
- 智腕科技例：「駭客（威脅）利用未限速 API（脆弱性）大量抓取健康資料（事件），導致個資外洩與罰款（後果）」。

## 2. 全景與準則

| 詞 | 白話 |
|---|---|
| 外部全景 | 文化、社會、政治、法規、財務、技術、經濟、自然、競爭環境；主要趨勢；外部關注方的關係與觀感 |
| 內部全景 | 治理與結構、政策目標、能力、資訊系統與決策過程、內部關注方、**文化**、採用的標準、**契約關係** |
| 風險準則（risk criteria） | 評估風險 **重大性** 的參照依據；以目標與內外部全景為基礎，可源自標準、法律、政策 |

對應 42001 §4.1：內外部議題就是內外部全景；§6.1.1 要建立 AI 風險準則。

## 3. 態度光譜（配對題高頻）

| 詞 | 白話 | 記法 |
|---|---|---|
| 風險態度（risk attitude） | 組織評鑑並最終 **追求、保留、承擔或迴避** 風險的取向 | 總稱 |
| 風險胃納（risk appetite） | 組織 **願意追求或保留** 的風險 **類型與數量** | 處理 **前** 的「想吃多少」 |
| 風險容忍度（risk tolerance） | 為達成目標，願意承受 **殘餘風險** 的程度；可受法規影響 | 處理 **後** 的「吞得下多少」 |
| 風險規避傾向（risk aversion） | 傾向避開風險的態度 | 是一種態度，不是處理方式 |
| 風險接受（risk acceptance） | 經告知後決定承擔某個風險；可不經處理或在處理過程中發生；**仍要監督與審查** | 是決定 |

## 4. 風險處理的七種方式（複選題高頻）

1. **避免**：決定不開始或停止引起風險的活動。
2. **承擔或增加風險** 以追求機會。
3. **移除風險來源**。
4. **改變可能性**。
5. **改變後果**。
6. **分擔**：與他方分擔，包括契約、保險、風險融資。
7. **保留**：經告知後決定保留。

補充：
- 處理負面後果的方式也稱減緩、消除、預防、降低。
- **處理可能產生新風險，或改變既有風險**，所以處理後要再評估。
- 31073 的 **風險分擔** 涵蓋「移轉」；法規可能限制、禁止或強制分擔。
- **殘餘風險** 可能包含 **未被鑑別出的風險**，也稱「保留風險」。

### 易混：避免 vs 規避傾向 vs 保留 vs 接受

| 詞 | 性質 | 例子 |
|---|---|---|
| 風險避免（avoidance） | 處理選項：不做或退出活動 | 不推出「憂鬱傾向偵測」功能 |
| 風險規避傾向（aversion） | 態度 | 董事會普遍保守 |
| 風險保留（retention） | 處理選項：承受可能的利得或損失，**包含接受殘餘風險** | 接受少量運動辨識錯誤 |
| 風險接受（acceptance） | 決定 | 管理審查核准殘餘風險 |

## 5. 控制、監督、審查

| 詞 | 白話 |
|---|---|
| 風險控制（risk control） | **維持或修改** 風險的措施，包括流程、政策、設備、實務；**不一定總能發揮預期效果** |
| 監督（monitoring） | **持續** 查核、觀察，找出與要求或預期績效的變化 |
| 審查（review） | 判定 **適合性、充分性、有效性** 的活動 |
| 風險報告 | 告知特定關注方風險現況與管理狀態 |
| 風險清冊（risk register） | 已鑑別風險的資訊紀錄，也叫風險日誌 |
| 風險剖繪（risk profile） | 任何一組風險的描述 |
| 風險彙整（risk aggregation） | 合併多個風險看整體 |
| 風險管理稽核 | 系統化、獨立、文件化地取得並客觀評估證據，判定風險管理架構是否充分且有效 |
| 韌性（resilience） | 組織在複雜多變環境中的 **調適能力**（注意：與 22989 的系統強韌性定義不同） |

### 易混：監督 vs 審查 vs 量測

- 監督是 **持續看狀態有沒有變**。
- 審查是 **判斷合不合適、夠不夠、有沒有效**，通常是定期的。
- 42001 §9.1 監督量測、§9.3 管理審查就是這兩個概念的應用。

## 6. 風險管理架構 vs 計畫 vs 政策

| 詞 | 層級 |
|---|---|
| 風險管理政策 | 整體意圖與方向的聲明 |
| 風險管理架構（framework） | 遍及組織、支撐設計、實施、監督、審查、改善的 **基礎與安排**；基礎包括政策、目標、承諾；安排包括計畫、關係、當責、資源、流程 |
| 風險管理計畫（plan） | 架構內，針對特定對象規定 **做法、管理要件、資源** 的方案；要件包括程序、責任、活動順序與時程 |

## 7. 溝通與諮詢

- **諮詢** 是在決策前的 **雙向** 溝通；是 **透過影響力** 影響決策，是決策的輸入，**不是參與決策**。
- **風險感知** 反映關注方的需求、議題、知識、信念與價值。

## 考試陷阱

- 「風險評鑑包含風險處理」→ 錯。
- 「風險胃納是處理後可承受的殘餘風險」→ 錯，那是容忍度。
- 「風險分擔不包括保險」→ 錯，保險是典型分擔。
- 「控制一定能降低風險」→ 錯，控制不一定發揮預期效果，所以要監督有效性。
- 「殘餘風險都是已知的」→ 錯，可能包含未鑑別風險。
- 「諮詢代表關注方參與決策」→ 錯，只是決策輸入。
- 「放棄機會不是風險」→ 錯，抓或不抓都是風險來源。
