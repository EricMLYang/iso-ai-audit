# ISO 19011 第 6 章 — 執行稽核（讀書筆記）

> 對應課程資源：課程參引〈執行 AIMS 稽核與驗證過程要求〉（單元 12、13、14；考試單元 3、4、5）。課程頁把 19011 §6 與 17021-1 §9 對照排列。
> 自己的話整理。17021-1 那一側的清單（起始會議 16 項、報告內容等）見 [ISO17021-1 筆記](ISO17021-1_驗證機構要求與驗證流程.md)；本檔聚焦 **19011 的指引** 與兩者的差異。

## 0. 全流程（排序題必背）

```
6.2 啟動稽核 → 6.3 準備稽核活動 → 6.4 執行稽核活動 → 6.5 準備與分發報告 → 6.6 完成稽核 → 6.7 稽核跟催
```

6.4 內部順序：

```
指派引導人員與觀察員 → 起始會議 → 稽核中溝通 → 資訊的可用性與取用 → 文件審查
→ 蒐集與查證資訊 → 產生稽核發現 → 決定稽核結論 → 總結會議
```

執行稽核的責任由 **稽核組長** 承擔，直到稽核完成。順序可依情況調整。

## 1. 啟動稽核（6.2）

### 與受稽方建立聯繫：組長要確認的事

a. 與受稽方代表的溝通管道
b. 執行稽核的 **職權**
c. 提供目標、範圍、準則、方法、稽核組成員（含技術專家）資訊
d. 索取規劃用資訊，包括受稽方 **已鑑別的風險與機會及處理方式**
e. 決定適用的法規與其他要求
f. 確認 **保密資訊** 揭露與處理的協議
g. 稽核安排與時程
h. 特定地點的進出、健康安全、保全、保密安排
i. 同意 **觀察員** 參與，以及引導人員或口譯需求
j. 受稽方特別關切的領域或風險
k. 解決與受稽方或委託方之間關於 **稽核組組成** 的議題

### 判定可行性（6.2.3）

看三樣東西是否可得：**足夠適當的資訊、受稽方的充分合作、充分的時間與資源**（含 ICT）。

稽核不可行時，**與受稽方協議後，向稽核委託方提出替代方案**。

## 2. 準備稽核活動（6.3）

### 文件化資訊審查（6.3.1）

目的有二：
- **了解** 受稽方的管理系統，準備稽核活動與工作文件。
- 建立文件化資訊 **概觀**，判斷是否符合準則，發現缺陷、遺漏、衝突。

審查對象包括管理系統文件與紀錄、**先前稽核報告**；要考量組織全景、規模、複雜度、風險，以及稽核範圍、準則、目標。

**課程重點：第一階段文件審查的不符合「不分級」**。因為多數驗證機構要求受稽方在第二階段開始前完成修正與矯正，所以文件審查階段發現的不符合不分主要或次要。這跟我們單元 4～10 作業做的「第一階段文件審查」直接相關。

### 風險導向規劃（6.3.2）

組長依稽核方案資訊與受稽方文件，用 **風險導向** 方法規劃。稽核計畫的詳細程度反映 **範圍、複雜度、未達成目標的風險**。

規劃時考慮：
a. 稽核組組成與整體能力
b. 適當的 **抽樣技術**（附錄 A.6）
c. 提升效率與效果的機會
d. **規劃不佳** 造成無法達成目標的風險
e. **稽核本身對受稽方造成的風險**，例如稽核員進入無塵室造成污染

合併稽核時，要注意過程間的交互作用，以及不同管理系統 **相互競爭的目標與優先順序**。

稽核計畫要有 **彈性**，以容許稽核中必要的變更；計畫要 **提交受稽方**；計畫有爭議時，由組長、受稽方，必要時加上方案管理者共同解決。

**稽核計畫要處理的事**：目標、範圍、準則與參考文件、地點（**實體與虛擬**）與日期時程（含與管理階層會面）、熟悉設施與過程的需要、**稽核方法**（現場或遠距、有無人員互動）與抽樣範圍、成員與引導人員觀察員口譯的角色、依風險配置資源。

### 指派稽核組工作（6.3.3）

組長與稽核組協商後指派。要考量稽核員的 **公正性、客觀性、能力**、資源效率，以及稽核員、見習稽核員、技術專家的不同角色。稽核中可變更指派。

### 準備工作文件（6.3.4）

可以是查檢表、抽樣細節、視聽資訊。

**查檢表等工作文件不宜限制稽核活動的範圍**，因為範圍可能隨稽核中蒐集的資訊而改變。這是情境題常見陷阱。

工作文件與稽核產生的文件化資訊，至少保留到稽核完成或方案規定的時間；涉及保密或財產權的資訊要隨時保護。

## 3. 執行稽核活動（6.4）

### 引導人員與觀察員（6.4.2）

- 經組長、委託方或受稽方核准後可同行，但 **不得影響或干擾** 稽核。
- 無法確保不干擾時，**組長有權拒絕觀察員出席某些活動**。
- 觀察員的進出、安全、保密安排由 **委託方與受稽方** 管理。
- **引導人員由受稽方指定**，職責：協助找受訪者並約時間地點、安排進出、確保稽核組與觀察員遵守現場規定、**代表受稽方見證稽核**、提供澄清。

### 起始會議（6.4.3）

**三個目的**：
1. 確認所有參加者 **同意稽核計畫**。
2. **介紹稽核組** 及其角色。
3. 確保所有規劃的活動 **可以實施**。

- 由 **組長主持**，受稽方管理階層參加；要給發問機會。
- 詳細程度依受稽方對稽核的熟悉度調整。小型組織內稽可以很簡單；其他情況可正式並 **保留出席紀錄**。
- 19011 特別提到：介紹 **如何管理稽核組成員可能對組織造成的風險**；說明 **何種狀況下可能終止稽核**；說明受稽方對發現或結論的 **回饋、抱怨、申訴** 機制。

### 稽核中溝通（6.4.4）— 情境題核心

| 情境 | 19011 指引 |
|---|---|
| 法規要求 **強制通報** 不符合 | 可能需要與外部關注方（例如主管機關）正式溝通 |
| 稽核組內部 | 定期商議、交換資訊、評估進度，必要時重新分派 |
| 證據顯示對受稽方有 **立即且重大的風險** | **毫不耽擱地報告受稽方**，適當時報告委託方 |
| 發現 **超出稽核範圍** 的議題 | 記錄並 **告知組長**，以便與委託方和受稽方溝通 |
| 證據顯示 **無法達成稽核目標**，例如發現主要不符合 | 組長向 **委託方與受稽方** 報告原因，決定措施：變更規劃、目標、範圍，或 **終止稽核** |
| 需要 **變更稽核計畫** | 由方案管理者與委託方審查接受，再提交受稽方 |

### 資訊的可用性與取用（6.4.5）

稽核方法取決於目標、範圍、準則、期間、場所。場所可以是 **實體或虛擬**。重點是 **在哪裡、何時、如何取得資訊**，跟資訊在哪裡產生或儲存無關。稽核中可能需要換方法。

### 稽核中的文件審查（6.4.6）

- 目的：判定符合性、蒐集支持其他活動的資訊。可與其他活動並行。
- **在稽核計畫規定的時限內拿不到足夠的文件化資訊**：組長告知方案管理者與受稽方，並決定稽核要 **繼續還是暫停** 到問題解決。

### 蒐集與查證資訊（6.4.7）

- 用 **適當抽樣** 蒐集，包括 **部門、活動、過程之間的介面** 資訊。
- **只有經過某種程度查證的資訊才能被接受為稽核證據**。查證程度低時，稽核員用專業判斷決定可信度。
- 導致稽核發現的證據要 **記錄**。
- 發現新的或改變的狀況、風險、機會時，稽核組要處理。

**蒐集方法**：訪談、觀察過程與活動、審查文件化資訊、**目視檢查**、**系統測試**。附錄 A.14 有選擇資訊來源的指引、A.15 有拜訪場所的指引、A.17 有訪談指引。

**從資訊到結論的流程**：

```
資訊來源 → 透過適當抽樣蒐集 → 查證 → 稽核證據 → 對照稽核準則評估 → 稽核發現 → 審查 → 稽核結論
```

**稽核軌跡（audit trail）**：沿著一個流程、一筆交易或一項控制，從頭追到尾找證據的方法。這正是單元 8 演練要做的「稽核軌跡」。

### 產生稽核發現（6.4.8）

- 依 **稽核準則** 評估 **稽核證據**，得到 **符合或不符合**。
- 若稽核計畫有規定，個別發現可包括：符合與 **良好實務**、**改善機會（OFI）**、**對受稽方的建議**。
- 不符合可依組織全景與風險分級，可 **定量**（例如 1～5 分）或 **定性**（例如主要、次要）。
- 要 **與受稽方一起審查**，確認發現準確且不符合已被理解。
- 盡量解決分歧；**未解決的記錄在報告中**。
- 與法規要求相關的符合或不符合，有時稱為 **守規或違規**。

分類細節見 [ISO19011_A18 筆記](ISO19011_A18_稽核發現的分類與寫法.md)。

### 決定稽核結論（6.4.9）

**總結會議前稽核組先商議**：對照目標審查發現；考量 **固有的不確定性** 後 **達成結論共識**；若計畫有規定就準備建議；適用時討論跟催。

**稽核結論要處理**：
a. 符合準則的程度與管理系統的 **穩健性**，含有效性、風險鑑別、處理風險措施的有效性
b. 管理系統的有效實施、維持、改進
c. 稽核目標達成、涵蓋範圍、滿足準則
d. 為了看趨勢，**不同領域、聯合稽核或先前稽核中的類似發現**

### 總結會議（6.4.10）

- **組長主持**，受稽方管理階層出席；適當時加上受稽部門負責人、**稽核委託方**、其他稽核組成員、其他關注方。
- 告知受稽方 **可能降低結論可信度的情況**。
- 若管理系統或與委託方有約定，對 **措施計畫的時限** 達成協議。
- 正式情況要有會議紀錄與出席紀錄；內稽可以較不正式。

**適當時要說明**：
a. 證據是 **樣本**，不一定完全代表整體有效性
b. 報告方法
c. 依議定過程處理發現的方式
d. **未充分處理發現的可能後果**
e. 以管理階層能理解與認同的方式呈現發現與結論
f. 稽核後活動：矯正措施的實施與審查、**抱怨與申訴** 處理

- 分歧要討論，能解決就解決，**未解決的全部記錄**。
- 若稽核目標有規定，可提出改進建議，但要 **強調建議沒有約束力**。

## 4. 稽核報告（6.5）

**19011 報告要包括**：目標、範圍、委託方、稽核組與受稽方參與人員、日期地點、準則、發現與證據、結論、**符合程度聲明**、**未解決的分歧**、**抽樣可能不具代表性的聲明**。

**適當時可加**：稽核計畫與時程、**遇到可能降低可靠性的障礙**、確認目標已達成、**未涵蓋的領域及理由**、主要發現摘要、**良好實務**、跟催措施計畫、**保密性質聲明**、與方案或後續稽核的關聯。

**分發**：
- 在 **議定期間內** 簽發；延遲要告知受稽方與方案管理者原因。
- 依方案標註日期、審查、接受。
- 分發給方案或計畫界定的關注方，注意 **保密**。

## 5. 完成稽核（6.6）

- 所有規劃活動都執行完，或 **經委託方同意**（例如遇到阻礙無法依計畫完成），稽核即完成。
- 文件化資訊依協議、方案與要求保存或處置。
- **未經委託方明確同意（適當時加上受稽方同意），不得揭露稽核資訊或報告**，除非法律要求。

## 6. 稽核跟催（6.7）

- 稽核結果可能指出需要 **修正、矯正措施或 OFI**。
- 這些措施 **通常由受稽方決定**，並在 **議定時限內** 完成；受稽方告知方案管理者或稽核組進度。
- 措施的 **完成與有效性要被查證**，查證可以是 **後續稽核的一部分**。
- 結果報告給方案管理者與委託方，供 **管理審查** 用。

### 修正 vs 矯正措施

| 詞 | 白話 | 智腕科技例 |
|---|---|---|
| 修正（correction） | 消除 **已發現** 的不符合 | 補上 AI 政策的核准簽名 |
| 矯正措施（corrective action） | 消除不符合的 **原因**，防止 **再發生** | 修改文件管制程序，系統強制核准後才能發布 |

### 查證 vs 確證（ISO 9000）

- **查證**：用客觀證據證實已滿足 **規定的要求**。
- **確證**：用客觀證據證實已滿足 **特定預期用途或應用** 的要求；條件可以是真實或模擬。

## 7. 19011 vs 17021-1 對照（易混）

| 主題 | 19011（指引，「宜」） | 17021-1（要求，「應」） |
|---|---|---|
| 適用 | 一、二方稽核為主 | 第三方驗證 |
| 稽核不可行 | 向委託方提替代方案 | 申請審查時婉拒並說明理由 |
| 無法達成目標 | 組長報告 **委託方與受稽方** | 組長報告 **客戶**，可能時報告 **驗證機構** |
| 改善機會 | 稽核計畫有規定時可給 **建議**（無約束力） | 可鑑別改善機會，但 **不得建議特定解決方案** |
| 不符合分級 | 定量或定性皆可 | 主要與次要 |
| 報告所有權 | 依方案 | **屬於驗證機構** |
| 追查頻率 | 依方案 | 每日曆年至少一次 |

## 情境題速判

| 情境 | 正確做法 |
|---|---|
| 稽核前發現受稽方資料庫因法務保留不能看 | 判定可行性；不可行時協議後向委託方提替代方案 |
| 查檢表沒列到，但現場看到重要問題 | 查檢表不限制範圍，可以追查 |
| 觀察員一直插話 | 組長可拒絕其出席某些活動 |
| 發現伺服器機房漏水，可能立即停機 | 毫不耽擱地報告受稽方 |
| 發現範圍外的部門也在用同一個 AI 模型且有問題 | 記錄並告知組長，由組長與委託方和受稽方溝通 |
| 約定時間內拿不到文件 | 組長告知方案管理者與受稽方，決定繼續或暫停 |
| 受訪者口頭說明，查不到任何紀錄 | 未經查證的資訊不能當證據 |
| 受稽方在總結會議不同意發現 | 討論；不能解決就記錄 |
| 稽核報告要寄給受稽方的客戶 | 未經委託方同意不得揭露 |

## 考試陷阱

- 「查檢表上沒有的項目不能稽核」→ 錯。
- 「第一階段文件審查發現的不符合要分為主要或次要」→ 依課程說明，通常不分級。
- 「稽核規劃只需考慮未達成稽核目標的風險」→ 錯，還要考慮稽核對受稽方造成的風險。
- 「矯正措施由稽核員決定」→ 錯，通常由受稽方決定。
- 「稽核建議對受稽方有約束力」→ 錯。
- 「所有資訊都可直接作為稽核證據」→ 錯，要經過某種程度的查證。
