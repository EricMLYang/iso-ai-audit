# ISO 19011 第 3 章 — 稽核詞彙：易混辨析（讀書筆記）

> 對應課程資源：課程參引〈詞彙〉（稽核指引，單元 3；考試單元 2）。課程頁為 19011:2026 版，定義多源自 ISO 9000:2026。
> 自己的話整理。基本表見 [詞彙速查.md](../詞彙速查.md) 的稽核段；本檔補 **2026 版新增或改寫的重點** 與 **易混配對**。

## 1. 稽核本身

- **稽核**：為取得 **客觀證據** 並 **客觀評估**，以判定 **稽核準則被滿足程度** 的 **系統化、獨立、文件化** 過程。
  記法：**系統、獨立、文件化**三個形容詞，加上兩次「客觀」。
- **內部稽核（第一方）**：由組織本身或代表組織執行。
- **外部稽核**：
  - **第二方**：由對組織有利益關係者執行，例如 **顧客**，或代表他們的人。
  - **第三方**：由 **獨立稽核組織** 執行，例如驗證機構、**政府機關與主管機關**。

## 2. 稽核型態

| 詞 | 定義重點 | 智腕科技例 |
|---|---|---|
| **合併稽核（combined）** | **單一受稽方**、**兩個以上管理系統** 一起稽核 | 同一次稽核 42001 ＋ 27001 |
| **聯合稽核（joint）** | **單一受稽方**、**兩個以上稽核組織** 一起稽核 | 兩家驗證機構一起稽核智腕科技 |
| **遠端稽核方法** | 在受稽方所在地 **以外任何地方** 執行稽核活動的方法 | 視訊審查雲端主控台 |

遠端稽核方法的三個備註：
1. 可與現場方法 **結合使用**，達成完整有效的稽核。
2. 可用於 **虛擬場所**：組織用線上環境工作，人員不受實體地點限制。
3. 稽核員 **在受稽方的 A 據點遠端稽核 B 據點**，也算遠端稽核方法。

## 3. 方案、計畫、範圍、準則（必考配對）

| 詞 | 定義 | 一句話 |
|---|---|---|
| **稽核方案** | 針對 **特定期間**、導向 **特定目的** 的一項或多項稽核的安排 | 一年的稽核行事曆 |
| **稽核計畫** | 一次稽核的 **活動與安排的描述** | 這一次稽核的議程 |
| **稽核範圍** | 稽核的 **程度與界限**；通常包括 **實體與虛擬地點**、職能、組織單位、活動、流程、**涵蓋期間** | 稽核哪裡、哪段時間 |
| **稽核準則** | 拿來跟客觀證據 **比較的一組要求** | 拿什麼當標準 |

**稽核準則可包括**：政策、程序、工作指導書、法律要求、**契約義務**、產業標準。

## 4. 證據、發現、結論（排序題）

| 詞 | 定義重點 |
|---|---|
| **客觀證據** | 支持某事物 **存在或真實性** 的資料；可透過觀察、量測、測試等取得 |
| **稽核證據** | 與稽核準則 **相關** 且 **可驗證** 的紀錄、事實陳述或其他資訊 |
| **稽核發現** | 稽核證據對照稽核準則 **評估的結果**；顯示符合或不符合；也可導致 **識別風險、改善機會、記錄良好實務** |
| **稽核結論** | 考量 **稽核目標與所有稽核發現** 後的稽核結果 |

**守規與違規**：稽核準則若是 **法律、法定或法規要求**，發現常稱為 **compliance／non-compliance**。

易混：
- 「客觀證據」是 **存在的資料**；「稽核證據」是 **跟準則相關且可驗證** 的資訊。所有稽核證據都要可驗證，但不是所有資料都跟準則相關。
- 「稽核發現」是 **單項評估結果**；「稽核結論」是 **綜合所有發現與目標** 後的整體結果。

## 5. 人與組織

| 詞 | 定義重點 | 陷阱 |
|---|---|---|
| **稽核委託方（audit client）** | **要求** 稽核的組織或個人 | **內稽時，委託方也可以是受稽方或方案管理者**；外稽要求可來自主管機關、契約方、潛在或現有顧客 |
| **受稽方（auditee）** | 被稽核的 **整個組織或其一部分** | — |
| **稽核組** | 一名或多名執行稽核的人，需要時由 **技術專家** 支援 | 要指定 **一名稽核員** 擔任組長；可包括 **見習稽核員** |
| **稽核員** | 執行稽核的人 | — |
| **技術專家** | 提供特定知識或專業；可涉及組織、活動、流程、產品、服務、專業領域、**語言或文化** | **不擔任稽核員** |
| **觀察員** | 陪同稽核組，但 **既不是稽核員也不是技術專家** | — |

注意：19011 第 3 章 **沒有定義「引導人員（guide）」**；17021-1 3.8 有定義陪檢員為「客戶指派協助稽核組的人」。

## 6. 管理系統相關

| 詞 | 定義重點 |
|---|---|
| **管理系統** | 組織中 **相互關聯或相互作用的要素** 集合，用來建立政策、目標，以及達成目標的流程。範圍可以是整個組織、特定職能、特定部門，或 **跨組織群體的職能** |
| **要求（requirement）** | **已陳述、通常隱含、或強制性** 的需求或期望；「通常隱含」指已屬慣例；「特定要求」指已被陳述的，例如寫在文件化資訊中 |
| **過程（process）** | 利用輸入產出 **預期結果** 的相互關聯或相互作用的活動集合 |
| **績效** | **可量測的結果**，可定量或定性 |
| **有效性（effectiveness）** | **規劃的活動被實現、規劃的結果被達成** 的程度 |
| **適任性（competence）** | **運用知識與技能達成預期結果** 的能力 |
| **風險** | 不確定性的效應（19011 版本 **沒有寫「對目標」**，跟 31000 不同） |
| **符合 / 不符合** | 要求被滿足 / 未被滿足 |

## 7. 改正、矯正、預防（必考三兄弟）

| 詞 | 消除什麼 | 目的 | 時間點 |
|---|---|---|---|
| **改正（correction）** | **已偵知的不符合** 本身 | 處理現狀 | 可在矯正措施之前、同時、之後 |
| **矯正措施（corrective action）** | 不符合的 **原因** | 防止 **再發生** | 不符合發生後 |
| **預防措施（preventive action）** | **潛在** 不符合或不欲情況的原因 | 防止 **發生** | 不符合發生前 |

- 不符合或潛在不符合 **可能有多個原因**。
- 改正的例子：重工、重評級。
- 高階結構（HLS）的管理系統標準，包括 42001，已 **不再有獨立的預防措施條款**，改由 **§6.1 風險與機會** 承擔預防功能。

智腕科技例：
- 改正：把未經核准就上線的模型版本 **回滾**。
- 矯正措施：在 CI/CD 加入 **核准關卡**，沒有核准紀錄不能部署。
- 預防措施：在風險評鑑中預先識別「未核准部署」風險並設計控制。

## 考試陷阱

- 「合併稽核是兩個稽核組織一起稽核」→ 錯，那是聯合稽核。
- 「內部稽核的委託方不可能是受稽方」→ 錯，可以是。
- 「觀察員可以兼任技術專家」→ 依定義，觀察員既不是稽核員也不是技術專家。
- 「矯正措施是為了防止發生」→ 錯，是防止 **再** 發生。
- 「稽核範圍只包括實體地點」→ 錯，也包括虛擬地點與涵蓋期間。
- 「要求只包括書面規定」→ 錯，也包括通常隱含與強制性的。
