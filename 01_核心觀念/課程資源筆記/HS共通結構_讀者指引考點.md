# 管理系統標準共通結構（HS／Annex SL）— 讀者指引考點（讀書筆記）

> 對應課程資源：單元 2〈管理系統標準共通結構〉（考試單元 1 核心）。
> 自己的話整理。HLS 條款架構見 [管理系統基礎_HLS_PDCA_風險思維.md](../管理系統基礎_HLS_PDCA_風險思維.md) §2；本檔專抓 **共通結構讀者指引裡的細節考點**。

## 1. 基本觀念

- **管理系統**：組織管理與業務相關的活動，以達成組織目標的方法。小組織可能只需要強力領導與清楚期望，不需要大量文件；高度監管產業可能需要大量文件。
- ISO 管理系統標準採 **過程導向**，用兩個工具實踐：**PDCA** 與 **風險思維**。
- ISO 有 **80 多種** 管理系統標準。42001 與 9001、14001、20000-1、22000、22301、27001、45001、50001 共用同一結構。
- **共通結構（HS, harmonized structure）**：相同的 **條款編號、條款標題、文字、通用術語與核心定義**。定義在 ISO/IEC 指令的 **Annex SL**。
- 好處：組織可以用 **單一（整合）管理系統** 同時滿足多個標準。

## 2. 助動詞（必考）

| 中文 | 英文 | 意義 |
|---|---|---|
| 應 | shall | **要求** |
| 宜 | should | **建議** |
| 可 | may | **允許** |
| 能 | can | **可能性或能力** |

**附註（Note）** 是提供理解或釐清要求的指引，**不是要求**。

## 3. 讀者指引中的細節考點

| 考點 | 重點 |
|---|---|
| **「決定（determine）」不等於要文件化** | HS 中很多「應決定」的要求，**不特別要求文件化資訊** 作為證據。稽核時可用訪談、觀察等方式確認 |
| **三種範圍不要混淆** | **標準的範圍**、**管理系統的範圍**、**驗證的範圍** 是三件事 |
| **組織** | 若組織是較大實體的一部分，「組織」只指管理系統範圍內的那一部分 |
| **最高管理階層** | 若範圍只涵蓋組織的一部分，最高管理階層指的是 **指導與控制那一部分** 的人 |
| **風險** | 不同專業領域對風險的理解不完全一致；HS 盡量保持一致，可參考 31000 |
| **文件化資訊** | 取代舊版的 documentation、documents、records、documented procedures；重點在 **資訊的交付** 而不是媒介；**凡提到文件化資訊，§7.5 的要求都適用** |
| **有效性 vs 效率** | **有效性（effectiveness）**：規劃活動實現、規劃結果達成的程度。**效率（efficiency）**：成果與所用資源的比較。HS **只用有效性** 談交付預期結果的能力 |
| **符合 vs 合規** | HS 用 **符合（conformity）**，**不用合規（compliance）**；合規相關要求參考 **ISO 37301** |
| **監督 vs 量測** | **量測**：決定一個值的過程。**監督**：決定系統、過程或活動的 **狀態**；監督 **可以但不一定** 涉及量測 |
| **持續改善用 continual 不用 continuous** | **continual** 是一段時間內反覆發生、**可以有間斷**；**continuous** 是 **不中斷**。HS 只用 continual |
| **不用「預防措施」** | HS 不使用 preventive action 一詞；**§6.1 因應風險與機會的行動** 就具有預防性 |
| **「機會」沒有定義** | HS 沒有定義「機會」，用 **字典意思**：使做某事成為可能的時間或情況 |

## 4. 各條款的意圖與指引重點

| 條款 | 意圖與指引重點 |
|---|---|
| **4.1 組織全景** | 議題可正可負。**2024 年 2 月 IAF 與 ISO 聯合聲明**：組織 **應決定氣候變遷是否為議題**。議題是決定範圍、風險機會、管理審查的重要依據 |
| **4.2 關注方** | 2024 修正加註：**關注方可能提出與氣候變遷相關的要求**。**並非所有關注方的要求都會成為組織的要求**；法律強制的、上級實體指定的、組織自願同意的，才成為要求。例如 9001 的主要關注方是 **顧客**，45001 是 **工作者** |
| **4.3 範圍** | 管理系統的可信度跟 **邊界與適用性的選擇** 很有關係；範圍聲明 **不應誤導關注方**；範圍要 **文件化** |
| **4.4 管理系統** | 「所需的流程」包括支持第 4～10 條的 **所有流程，不論內部或外部提供** |
| **5.1 領導與承諾** | 用「確保（ensuring）」表示 **最高管理階層可以授權他人執行，但仍要負責確保**。要確保管理系統 **不被視為與業務分離**。「業務」可廣義解釋，包括非營利與政府。有些標準區分最高管理階層與 **治理機構**（37001 的定義：對組織活動、治理、政策負最終責任，最高管理階層向其報告） |
| **5.2 政策** | 四要素：適合目的、包括目標或提供設定目標的框架、**承諾滿足適用要求**、**承諾持續改善**；文件化、內部溝通、適用時提供給關注方。指引提醒：期望管理系統 **完全保證** 符合所有要求是不切實際的 |
| **5.3 角色責任權限** | 至少指派：確保管理系統符合標準、向最高管理階層報告績效 |
| **6.1 風險與機會** | 目的：確保達成預期結果、**預防或減少非所欲的影響**、持續改善。要規劃行動、如何整合進流程、**如何評估有效性**。**§4 → §6.1 → §8.1** 的連結要維持 |
| **6.2 目標** | 七個特性：與政策一致、**可量測（如果可行）**、考慮適用要求、被監控、被溝通、適時更新、文件化。規劃：做什麼、資源、誰負責、何時完成、**如何評估結果**。**可量測不一定要量化**，有證據支持的定性結果（例如是否）也可以 |
| **6.3 變更規劃** | 引發變更的情況可以是計畫或非計畫的，但 **變更本身要有計畫地進行** |
| **7.1～7.4** | 認知要求放 7.3，不要跟能力混在一起。**能力要保存文件化資訊作為證據** |
| **7.5 文件化資訊** | 建立與更新時確保：**識別與描述**、**格式與媒介**、**審查與核准**。管制：可用性、保護（機密、不當使用、完整性）、分發存取檢索使用、儲存與保存（含 **可讀性**）、**變更管制**、**保留與處置**；**外來文件** 也要識別與管制 |
| **8.1 運作** | 為流程制定 **準則**、依準則控制；保存足以 **相信流程依規劃執行** 的文件；**控制計畫中的變更**、**審查非預期變更的後果**；**外部提供的流程、產品、服務要受控制**，即使外部提供者 **不在管理系統範圍內**，對其提供物的控制 **仍在範圍內** |
| **9.1** | 決定監督量測什麼、方法、何時執行、何時分析評估；保存結果的文件化資訊 |
| **9.2 內部稽核** | 依規劃期間執行，確認是否 **符合（組織自己的要求與標準要求）** 且 **有效實施與維持**。稽核方案要考慮 **流程重要性與以往稽核結果**；選稽核員確保 **客觀與公正**；結果報告相關管理階層 |
| **9.3 管理審查** | 確保 **持續的適合性、充分性、有效性**。輸入五項：前次行動狀態、內外部議題變化、**關注方需求變化**、績效趨勢（不符合與矯正、監督量測、稽核結果）、改善機會。輸出：持續改善的決定、**管理系統變更需求** |
| **10.1 持續改善** | 改善 **適合性、充分性、有效性**；形式可包括矯正措施、持續改善、**突破性改變、創新、組織再造** |
| **10.2 不符合與矯正措施** | 反應（控制與修正、處理後果）→ 評估是否要消除原因（審查、找原因、**看是否有類似不符合存在或可能發生**）→ 實施 → **審查有效性** → 必要時變更管理系統。**矯正措施要與不符合的影響相稱**；組織 **不一定** 總能找出或消除原因，會考慮技術可行與成本效益 |

## 5. 42001 在 HS 之外多了什麼（對照）

| HS 共通條款 | 42001 額外加的 |
|---|---|
| 4.1 | 判定組織的 **AI 角色**；考慮 **AI 系統的預期目的**；**應決定氣候變遷是否為相關議題**（2024 修正，與所有 HS 標準相同） |
| 6.1.1 | 建立 **AI 風險準則** |
| 6.1.2～6.1.3 | **AI 風險評鑑**、**AI 風險處理**、**SoA**、比對 **附錄 A** |
| 6.1.4 | **AI 系統衝擊評鑑** |
| 8.2～8.4 | 依計畫執行 AI 風險評鑑、處理、衝擊評鑑 |
| 附錄 A～D | 控制、指引、目標與風險來源、跨領域使用 |

## 考試陷阱

- 「should 表示要求」→ 錯，表示建議。
- 「標準中所有『決定』都要有文件化資訊」→ 錯。
- 「管理系統範圍等於驗證範圍」→ 錯。
- 「HS 鼓勵使用 continuous improvement」→ 錯，用 continual。
- 「HS 用合規（compliance）描述滿足要求」→ 錯，用符合（conformity）。
- 「目標必須量化」→ 錯，可量測（如果可行），定性也可以。
- 「外部提供者不在範圍內，就不需控制其提供物」→ 錯。
- 「最高管理階層必須親自執行 5.1 的每一項」→ 錯，可授權，但要確保。
- 「關注方的所有需求都是組織的要求」→ 錯。
- 「監督一定包含量測」→ 錯。
