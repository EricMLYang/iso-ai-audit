# ISO 19011 第 7 章 — 稽核員能力與評估（讀書筆記）

> 對應課程資源：課程參引〈稽核員能力一般要求〉、〈AI 管理系統驗證 - 稽核員能力要求〉（單元 3 必看；考試單元 2）。自己的話整理。
> AIMS 驗證稽核員的具體門檻，例如 4 年經驗、24 小時訓練，見 [ISO42006 筆記](ISO42006_AIMS驗證機構要求.md) §4。

## 1. 核心觀念

- 能力（competence）＝ **運用知識與技能達成預期結果** 的能力。
- 評估時要考量：**個人行為** ＋ 從 **教育、工作經驗、稽核員訓練、稽核經驗** 得到的知識與技能。
- 稽核組 **每位成員不必有相同能力**，但 **整體能力** 要足以達成稽核目標。

## 2. 評估的四個步驟（排序題）

1. **決定** 需要的能力
2. 建立 **評估準則**
3. 選擇 **評估方法**
4. **執行** 評估

評估結果用於：**遴選稽核組成員**、找出能力改善需求（例如加訓）、持續績效評估。

## 3. 決定所需能力時考慮（7.2.1）

受稽方的規模、性質、複雜度、產品服務過程；稽核方法；管理系統專門領域；管理系統的複雜度；**風險與機會的類型與等級**；方案目標與範圍；**達成目標的不確定性**；委託方或關注方的附加要求。

## 4. 十三項個人行為（7.2.2）— 配對題高頻

| # | 行為 | 關鍵詞 |
|---|---|---|
| a | 具道德觀 | 公平、真實、誠懇、誠實、謹慎 |
| b | 心胸開闊 | 願意考量不同觀點 |
| c | 外交手腕 | 圓融待人 |
| d | 善於觀察 | **主動察覺** 周遭情況與活動 |
| e | 敏銳感知 | 感受並 **理解** 現況 |
| f | 能變通 | 適應不同情況 |
| g | 不屈不撓 | 堅持、專注達成目標 |
| h | 果斷 | 基於邏輯分析 **及時** 下結論 |
| i | 自立 | **獨立** 作業，同時與他人有效互動 |
| j | 行事正直 | 即使不受歡迎、引起對立，仍負責且合乎道德 |
| k | 願意改進 | 從情況中學習 |
| l | 文化敏感 | 尊重受稽方文化 |
| m | 協同合作 | 與稽核組及受稽方有效互動 |

易混配對：
- 「受稽方主管施壓要撤銷不符合，稽核員仍堅持」→ **行事正直**（j）。也可聯想到 17021-1 的「恐嚇」威脅。
- 「主動注意到機房門沒關」→ **善於觀察**（d）。
- 「察覺受訪者神情緊張，換個方式提問」→ **敏銳感知**（e）。
- 「稽核時間被壓縮仍完成重點抽樣」→ **不屈不撓**（g）或 **能變通**（f）。

## 5. 稽核員共通知識與技能（7.2.3.2）四大領域

| 領域 | 重點 |
|---|---|
| a. 稽核原則、程序、方法 | 風險導向；規劃安排；在時程內完成；聚焦重點；口頭與書面溝通（含透過口譯）；**訪談、傾聽、觀察、審閱文件** 蒐集資訊；了解 **抽樣** 的適當性；考量技術專家意見；查證資訊的相關性與準確性；確認證據 **充分且適當**；評鑑影響可靠性的因素；文件化與報告；**保密與資安** |
| b. 管理系統標準與參考文件 | 標準與指引；受稽方的應用；過程間的交互作用；多標準的優先性；應用於不同情境 |
| c. 組織及其全景 | 關注方需求；組織型態、治理、規模、結構；業務與管理概念；**文化與社會** |
| d. 法令法規及其他要求 | 法規與主管機關；基本法律術語；合約與責任 |

**重要備考**：了解法規 **不等於** 有法律專業；**管理系統稽核不應被視為法遵稽核**。

## 6. 專門領域與特定產業能力（7.2.3.3）

稽核組要 **整體** 具備。各管理系統的具體能力要求出處：

| 管理系統 | 能力要求出處 |
|---|---|
| ISMS（27001） | ISO/IEC 27006-1 附錄 A |
| PIMS（27701） | ISO/IEC 27706 附錄 C |
| **AIMS（42001）** | **ISO/IEC 42006 第 7 章** |

## 7. 稽核組長的額外能力（7.2.3.4）

a. 依成員能力 **規劃與分派** 工作
b. 與受稽方 **最高管理階層討論策略議題**，判斷其評估風險與機會時是否考慮過
c. 建立組內合作關係
d. 管理稽核過程：有效用資源、**管理達成目標的不確定性**、**保護組員健康安全**、指導組員與見習稽核員、**預防並解決衝突**（含組內衝突）
e. 代表稽核組與方案管理者、委託方、受稽方溝通
f. 領導稽核組 **達成稽核結論**
g. 準備並完成 **稽核報告**

多專門領域稽核時，組長要了解每個標準的要求，並 **知道每位稽核員在各領域能力的界限**。

## 8. 如何取得能力（7.2.4、7.2.5）

- 完成涵蓋共通知識技能的 **訓練**。有考試的課程要 **通過考試** 才算完成，這就是我們這門課的情況。
- 在技術、管理、專業職位上的 **工作經驗**（判斷、決策、解決問題、溝通）。
- 專門領域與產業的教育、訓練、經驗。
- 在同領域稽核員 **督導下** 取得稽核經驗。
- 稽核組長需要 **更多稽核經驗**，宜在 **不同** 稽核組長的指導下取得。

## 9. 評估準則（7.3）

- **定性**：訓練或工作中展現的行為、知識、技能。
- **定量**：工作與教育年數、稽核次數、訓練時數。

## 10. 六種評估方法（7.4 表 2）— 配對題必考

要用 **兩種以上** 方法合併評估。

| 方法 | 目的 | 例子 |
|---|---|---|
| **紀錄審查** | 查證背景 | 學歷、訓練、職歷、稽核經驗紀錄 |
| **回饋** | 了解他人對其表現的觀察 | 問卷、推薦信、**抱怨**、績效評估、同儕審查 |
| **面談** | 評估專業行為與溝通、測試知識 | 個人訪談 |
| **觀察** | 評估行為與 **應用** 能力 | **角色扮演、見證稽核**、在職表現 |
| **測試** | 評估行為、知識、技能及應用 | 口試、筆試、心理測驗 |
| **稽核後審查** | 了解在稽核中的表現，找優勢與改進點 | 審查報告、與組長討論、受稽方回饋 |

易混：「見證稽核」屬於 **觀察**，不是稽核後審查；「審查稽核員寫的報告」屬於 **稽核後審查**。

## 11. 執行評估與持續發展（7.5、7.6）

- 不符準則的稽核員：**加訓、累積工作或稽核經驗，再重新評估**。
- 維持能力：**定期參與稽核** ＋ **持續專業發展（CPD）**，例如工作經驗、訓練、自學、教練指導、研討會。
- CPD 要考慮：個人與組織需求的變化、**稽核實務與技術的發展**、標準與指引的變化、產業或專門領域的變化。
- 方案管理者要建立持續評估稽核員與組長績效的機制。

## 考試陷阱

- 「稽核組每位成員都必須具備相同能力」→ 錯。
- 「稽核員應具備法律專業，以進行法遵稽核」→ 錯。
- 「評估稽核員只需一種方法即可」→ 錯，宜用兩種以上。
- 「見證稽核屬於稽核後審查」→ 錯，屬於觀察。
- 「稽核組長能力應在同一位組長指導下累積」→ 宜在 **不同** 組長指導下。
