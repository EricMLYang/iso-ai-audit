# ISO 19011 第 4 章 — 七項稽核原則：情境判斷（讀書筆記）

> 對應課程資源：課程參引〈稽核原則〉（單元 3 必看；考試單元 2）。課程頁為 19011:2026 版。
> 自己的話整理。基本表格見 [稽核與驗證_ISO19011_17021.md](../稽核與驗證_ISO19011_17021.md) §3；本檔補 **每項原則的細節** 和 **情境配對**。

## 為什麼要有原則

堅守原則才能讓 **不同稽核員在類似情況下獨立作業，仍得出類似結論**，結論才會相關且充分。第 5～7 章的指引都建立在這七項原則上。

## 七項原則細節

| 原則 | 細節（自己的話） |
|---|---|
| **1. 正直（integrity）** | 專業素養的基礎。四件事：合乎倫理、誠實負責；**只在具備能力時** 才執行稽核；公正不偏頗；**警覺任何可能影響判斷的因素** |
| **2. 公平陳述（fair presentation）** | 真實準確地報告。發現、結論、報告要如實反映稽核；**重大障礙** 與 **未解決的分歧** 要報告；溝通要真實、準確、客觀、及時、清楚、完整 |
| **3. 盡專業注意（due professional care）** | 不論工作重要程度、委託方信任程度，都要盡應有注意；關鍵是 **在所有情況下做出合理判斷** |
| **4. 保密（confidentiality）** | 資訊的安全與隱私。審慎使用與保護資訊；**不得為個人利益**，也不得損害受稽方合法利益 |
| **5. 獨立（independence）** | **公正性與結論客觀性的基礎**。可行時獨立於受稽活動；任何情況都不受偏見與利益衝突影響；結論 **只建立在證據上**。**內部稽核員無法獨立時，仍要盡力消除偏見** |
| **6. 證據為憑（evidence-based）** | 達成 **可信賴且可再現** 結論的方法。證據要 **可驗證**；因為時間資源有限，所以建立在 **抽樣** 上；抽樣與對結論的信賴程度密切相關 |
| **7. 風險導向（risk-based）** | 考量風險與機會，影響方案與稽核的規劃、執行、報告，讓稽核 **聚焦於重要事項** |

記法：**「正公專密獨證險」**。

## 易混辨析

| 一對 | 差別 |
|---|---|
| 正直 vs 獨立 | 正直是 **個人品格**（誠實、能力內做事）；獨立是 **與受稽活動的關係**（不稽核自己的工作、無利益衝突） |
| 公平陳述 vs 證據為憑 | 公平陳述講 **怎麼報告**（如實、含障礙與分歧）；證據為憑講 **怎麼得出結論**（可驗證、抽樣） |
| 獨立 vs 公正性 | 獨立是 **公正性的基礎**；17021-1 把公正性定義為「存在客觀性」 |
| 盡專業注意 vs 風險導向 | 專業注意是 **態度與判斷力**；風險導向是 **資源配置與聚焦方法** |

## 情境 → 原則（配對題練習）

| 情境 | 主要對應原則 |
|---|---|
| 稽核員被派去稽核自己上個月參與設計的資料標註流程，他婉拒了 | 獨立 |
| 稽核員發現自己不懂深度學習，主動請組長加派技術專家 | 正直（只在具備能力時執行） |
| 報告寫明「受稽方拒絕提供模型訓練紀錄，第 3 項目標無法評估」 | 公平陳述（報告重大障礙） |
| 受稽方不同意某項不符合，報告仍記錄雙方分歧 | 公平陳述 |
| 稽核員把受稽方的客戶名單拍照帶走 | 違反保密 |
| 稽核員用稽核中得知的未公開財報資訊買股票 | 違反保密（為個人利益） |
| 只聽部門經理口頭保證就寫「符合」 | 違反證據為憑 |
| 抽樣 25 筆變更紀錄，依結果下結論並註明抽樣限制 | 證據為憑 |
| 把大部分時間放在高風險的健康預警模型，少放在低風險的內部排班工具 | 風險導向 |
| 即使是例行的小型內稽，仍仔細核對每份證據的日期與版本 | 盡專業注意 |
| 稽核員收到受稽方送的高價禮品後，對發現手下留情 | 違反正直與獨立 |
| 內部稽核員只能稽核自己部門的上游流程，盡力保持客觀並請同事複核 | 獨立（內稽無法完全獨立時的做法） |

## 跟 17021-1 驗證原則對照

| 19011 稽核原則 | 17021-1 驗證原則 |
|---|---|
| 正直、公平陳述、盡專業注意、保密、獨立、證據為憑、風險導向 | 公正性、能力、職責、公開、機密性、對抱怨的回應、風險導向 |

兩邊都有 **保密** 與 **風險導向**。17021-1 多了 **公開** 與 **對抱怨的回應**，因為那是驗證機構對大眾的責任。

## 考試陷阱

- 「內部稽核員無法獨立時，就不適用獨立原則」→ 錯，仍要盡力消除偏見、促進客觀。
- 「稽核結論可以基於稽核員的經驗推斷」→ 錯，只建立在證據上。
- 「公平陳述只要求報告不符合事項」→ 錯，還要報告重大障礙與未解決分歧。
- 「證據為憑要求檢查所有紀錄」→ 錯，以抽樣為基礎。
