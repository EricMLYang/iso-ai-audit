# ISO/IEC 17021-1:2015 — 驗證機構要求與驗證流程（讀書筆記）

> 對應課程資源：課程參引〈ISO/IEC 17021-1, 管理系統驗證要求〉、〈驗證相關詞彙〉（單元 3、12、13、14；考試單元 3、4、5）。
> 自己的話整理。總覽見 [稽核與驗證_ISO19011_17021.md](../稽核與驗證_ISO19011_17021.md) §7、§8；本檔補 **數字、清單、情境題** 細節。

## 0. 定位

- 17021-1 是 **驗證機構（CB）** 的要求，屬於 **第三方** 符合性評鑑。
- 可作為 **認證機構** 評鑑驗證機構的依據。
- AIMS 驗證再加 42006，見 [ISO42006 筆記](ISO42006_AIMS驗證機構要求.md)。

## 1. 必背詞彙

| 詞 | 白話 |
|---|---|
| 公正性（impartiality） | **存在客觀性**；利益衝突不存在或已解決 |
| 管理系統顧問 | 參與建立、實施、維持管理系統，例如寫手冊、給具體解決方案 |
| 驗證稽核 | 包括 **初次、追查（surveillance）、重新驗證**，也可包括 **特別稽核** |
| 聯合稽核 | 兩個以上稽核機構稽核同一客戶 |
| 合併稽核 | 同時依兩個以上標準稽核同一客戶 |
| 整合稽核 | 客戶已把多個標準整合為單一管理系統，依多個標準稽核 |
| 陪檢員（guide） | **客戶指派** 來協助稽核組的人 |
| 觀察員（observer） | 陪同稽核組但 **不執行稽核** 的人 |
| 技術專家 | 提供特定知識，**不能擔任稽核員**，要由稽核員陪同 |
| 稽核時間 | 規劃並完成完整有效稽核所需的時間 |
| 稽核時程（duration） | 稽核時間中 **從起始會議到結束會議** 的部分 |

**什麼不算顧問**：一般性訓練（不對特定客戶給解法）、解釋驗證規範的意義、**鑑別改善機會**、解釋理論方法工具、分享非機密的最佳實務。

## 2. 驗證的七項原則（§4）

**公正性、能力、職責、公開、機密性、對抱怨的回應、風險導向**。

記法：**「公能職、開密抱險」**。注意這跟 19011 的七項稽核原則不同。

| 19011 稽核原則 | 17021-1 驗證原則 |
|---|---|
| 誠正、公正呈現、專業注意、保密、獨立、證據導向、風險導向 | 公正性、能力、職責、公開、機密性、抱怨回應、風險導向 |

### 職責原則的關鍵句

- 符合標準並達成預期結果的責任在 **客戶**，不在驗證機構。
- 驗證機構的責任是評鑑足夠的客觀證據並據以做驗證決定。
- 稽核是 **抽樣**，所以不保證百分之百符合。

### 公正性的四種威脅 — 配對題必考

| 威脅 | 例子 |
|---|---|
| **自我利益** | 驗證費用是收入來源；稽核員持有客戶股票 |
| **自我審查** | 驗證機構先當顧問，再稽核同一系統 |
| **熟悉（信任）** | 太熟悉或太信任受稽方，就不去找證據 |
| **恐嚇** | 受稽方威脅要換掉稽核員或向上級投訴 |

## 3. 公正性的具體規定（§5.2）— 數字題

| 規定 | 內容 |
|---|---|
| 不得當顧問 | 驗證機構及同一法人實體 **不得提供管理系統顧問** |
| 不得做內稽 | 不得為其驗證客戶做內部稽核；做過內稽要 **至少隔 2 年** 才能驗證該系統 |
| 關係機構做過顧問 | 顧問結束後 **至少 2 年** 才能驗證 |
| 前顧問人員 | 顧問結束後 **至少 2 年** 才能參與該客戶的稽核 |
| 外包稽核 | **不得外包給顧問組織**；個別簽約的稽核員不算外包 |
| 行銷 | 不得與顧問組織連結；不得暗示用某顧問「驗證更簡單、更快、更便宜」 |
| 子公司 | 驗證機構完全擁有的子公司向母公司申請驗證，是不可接受的威脅 |
| 不驗證同業 | 驗證機構不得驗證另一驗證機構的品質管理系統 |
| 人員揭露 | 人員要揭露任何可能的利益衝突 |

## 4. 資源與外包（§7）

- 稽核員的初次能力評估，要由勝任的評估員 **觀察稽核員實際執行一次稽核** 後決定。
- 稽核員要定期接受 **現場評估**，監督方式結合現場評估、報告審查、客戶回饋。
- 外部稽核員與技術專家要簽書面協議，承諾保密、公正，並揭露與受稽組織的關係。
- **驗證決定不得外包**。外包的其他活動仍由驗證機構負全責。

## 5. 資訊、證書與標誌（§8）

- 公開資訊：稽核過程、驗證決定的過程、驗證方案、標誌使用、抱怨與申訴處理、公正性政策。
- 證書要包含：客戶名稱與地點、生效日（**不得早於驗證決定日**）、到期日、唯一編號、標準與版次、範圍、驗證機構與標誌。
- **驗證標誌不得用在產品或產品包裝上**，也不得用在實驗室測試、校正、檢驗報告上。
- 客戶不得暗示驗證涵蓋產品，或涵蓋範圍外的活動與場所；驗證終止時要停止引用。
- 已驗證客戶的重大變更（法律、所有權、組織、地址、範圍、管理系統）要 **即時通知** 驗證機構。

## 6. 驗證週期與時間表 — 數字題高頻

```
申請 → 申請審查 → 稽核方案 → 第一階段 → 第二階段 → 驗證決定 → 發證
     → 第 1 年追查 → 第 2 年追查 → 第 3 年重新驗證 → 新週期
```

| 規則 | 數字 |
|---|---|
| 驗證週期 | **3 年**，從 **驗證決定** 起算 |
| 追查稽核頻率 | 重新驗證年以外，**每個日曆年至少一次** |
| 首次追查 | 驗證決定後 **不超過 12 個月** |
| 主要不符合未於第二階段後完成查證 | **6 個月** 內查證不了，要 **再做一次第二階段** |
| 驗證到期後恢復 | 到期後 **6 個月內** 可恢復，前提是重要的重新驗證活動已完成，否則至少再做第二階段 |
| 暫時終止 | 多數情況 **不超過 6 個月** |
| 客戶紀錄保存 | **目前週期加一個完整週期** |
| 驗證機構內稽 | **至少每 12 個月**，穩定時可降低頻率 |
| 驗證機構管理審查 | **至少每年一次** |

### 申請時要提供的資訊（§9.1.1）

期望的範圍、場所、流程、人力與技術資源、法定義務、**影響符合性的外包流程**、申請的標準、**是否接受過顧問服務，由誰提供**。

### 申請審查要確認（§9.1.2）

資訊足以發展稽核方案、歧見已解決、**驗證機構有能力**、已考慮範圍、場所、稽核時間、語言、安全、公正性威脅。婉拒時要記錄理由並向客戶說明。

### 決定稽核時間的考量（§9.1.4）

標準要求、複雜度、技術與法規狀況、**外包**、先前稽核結果、場所規模與數量、風險、是否合併、聯合或整合稽核。

- **往返交通時間不計入**。
- 技術專家、翻譯、口譯、觀察員、見習稽核員的時間 **不計入** 稽核時間；用口譯可能需要額外時間。
- 稽核時間及其正當性要記錄。

### 多場所抽樣

只有 **相同活動** 的多場所才適合抽樣；抽樣計畫的合理性要書面化。

## 7. 規劃稽核（§9.2）

**稽核目標由驗證機構決定**；範圍與準則 **與客戶討論後確定**。

稽核目標應包括：
- 判定與稽核準則的符合性。
- 判定管理系統確保符合法律、法規、合約要求的 **能力**。注意：**驗證稽核不是法遵稽核**。
- 判定有效性。
- 適當時，鑑別改善領域。

稽核準則包括：標準要求，以及 **客戶自己訂的過程與文件**。

### 稽核組組成考量

目標、範圍、準則、時間；是否合併、聯合或整合；整體能力；驗證要求；**語言文化**。合併稽核的組長至少要對其中一個標準有深入認識。

| 角色 | 規則 |
|---|---|
| 見習稽核員 | 要有一位稽核員當 **評估員**，對見習者的活動與發現負最終責任 |
| 觀察員 | 出席與理由要 **事先** 經驗證機構與客戶同意；不得干擾稽核 |
| 技術專家 | 角色事先經雙方同意；不得當稽核員；**要由稽核員陪同** |
| 陪檢員 | 除非另有協議，每位稽核員都有陪檢員；負責安排訪談、帶路、確保遵守安全規定、**代表客戶見證稽核**、應要求提供澄清；不得影響稽核結果 |

### 稽核計畫至少包含

目標、準則、範圍、現場活動的日期與地點、時程、稽核組成員與陪同人員的角色職責。**第一階段不要求正式稽核計畫**。

稽核組名單要事先提供給客戶，讓客戶有時間 **對特定成員提出異議**；異議有效時要重組。

## 8. 第一階段 vs 第二階段（§9.3）

| | 第一階段 | 第二階段 |
|---|---|---|
| 目的 | 文件審查、準備度評估、規劃第二階段 | 評估 **實施情形，含有效性** |
| 地點 | 可部分在現場，**有助於達成目標** | **必須在客戶現場** |
| 計畫 | 不要求正式稽核計畫 | 要稽核計畫 |
| 輸出 | **書面結論**，含可能在第二階段被列為不符合的領域；不需完整報告 | 稽核報告 |

**第一階段要做的事**：審查文件化資訊；評估場所狀況；了解客戶對標準的理解，特別是 **關鍵績效、重大事項、過程、目標**；取得範圍、場所、流程設備、控制程度、**適用法規** 資訊；審查第二階段資源配置並協議細節；確認 **是否已規劃並執行內部稽核與管理審查**。

**第一、二階段的間隔**：要給客戶時間解決第一階段發現的問題。有重大變更時，考慮重做部分或全部第一階段。第一階段結果可能導致第二階段 **延後或取消**。

**第二階段至少稽核**：所有要求的符合證據；關鍵績效目標的監督、量測、報告、審查；法規與合約遵循的能力與績效；**作業管制**；內部稽核與管理審查；政策的管理職責。

## 9. 起始會議（§9.4.2）— 情境題、排序題

由 **稽核組長** 主持，與客戶管理階層一起開。內容：

1. 介紹參與者與角色。
2. 確認 **驗證範圍**。
3. 確認稽核計畫：類型、範圍、目標、準則、變更、結束會議時間、臨時會議。
4. 確認正式溝通管道。
5. 確認資源與設施。
6. 確認 **保密** 事宜。
7. 確認工作安全、緊急與安全程序。
8. 確認陪檢員與觀察員的角色與身分。
9. 報告方法，含 **發現的分級**。
10. 稽核可能 **提前終止的條件**。
11. 確認稽核組長與稽核組代表驗證機構對稽核負責。
12. 先前發現的現況。
13. 以 **抽樣** 為基礎的方法。
14. 稽核語言。
15. 稽核中會告知客戶進度與疑慮。
16. 給客戶提問的機會。

## 10. 稽核中（§9.4.3～9.4.5）

- 稽核組定期評估進度、交換資訊；組長視需要 **重新分配工作**，定期告知客戶進度與疑慮。
- **證據顯示稽核目標無法達成，或有直接重大風險（例如安全）時**：組長向客戶報告，可能時也向驗證機構報告，決定行動。行動可能是 **重新確認或修改稽核計畫、改變目標或範圍、終止稽核**。組長要向驗證機構報告結果。
- 需要改變稽核範圍時，組長與客戶審查並向驗證機構報告。
- 收集資訊方法：**訪談、觀察過程與活動、審查文件與紀錄**；要透過抽樣取得並查證。
- **不符合不得記錄為改善機會**。
- 不符合要有明確陳述與客觀證據，**與客戶討論** 確保證據正確且被理解；但稽核員 **要避免建議原因與解決方案**。
- 組長要試圖解決分歧，未解決的要記錄。

## 11. 準備稽核結論（§9.4.6）

結束會議前，稽核組要：審查發現並 **分類不符合**；考量抽樣的不確定性後 **同意稽核結論**；同意後續行動；確認稽核方案是否適當或需要修改（範圍、時間、追查頻率、能力）。

## 12. 結束會議（§9.4.7）

由稽核組長主持，**記錄出席者**。目的是說明稽核結論與 **驗證建議**。不符合要以可被理解的方式說明，並 **同意回覆期限**。

「被理解」**不等於** 客戶接受不符合。

內容：
1. 證據基於 **抽樣**，所以有不確定性。
2. 報告的方法與時限，含發現的分級。
3. 驗證機構處理不符合的流程，及對驗證狀態的影響。
4. 客戶提出 **修正與矯正措施計畫** 的時限。
5. 驗證機構的後續活動。
6. **抱怨與申訴** 的處理流程。

客戶可提問；分歧要討論，能解決就解決，**未解決的要記錄並提交驗證機構**。

## 13. 稽核報告（§9.4.8）

- 每次稽核都要提供書面報告；可鑑別改善機會，但 **不得建議特定解決方案**。
- 報告 **所有權屬於驗證機構**；**稽核組長負責報告內容**。

報告要包括：驗證機構、客戶與代表、**稽核類型**、準則、目標、範圍與時間、**與稽核計畫的偏差及理由**、影響方案的重大議題、稽核組成員與陪同人員、日期地點、發現與結論、**前次稽核後的重大變更**、未解決議題、是否合併聯合整合、**抽樣免責聲明**、稽核組建議、標誌使用是否受控、**前次不符合矯正措施的有效性**。

還要包含：管理系統符合性與有效性的聲明（含內稽與管審）、**驗證範圍適當性的結論**、確認已達成稽核目標。

## 14. 不符合的後續（§9.4.9、9.4.10）

- 客戶要在期限內 **分析原因**，說明已採取或計畫採取的 **修正與矯正措施**。
- 驗證機構審查並決定是否接受，並查證有效性；結果告知客戶。
- 查證方式可能是：**額外的完整稽核、額外的有限稽核、或書面證據（下次稽核確認）**。

## 15. 驗證決定（§9.5）

- 做決定的人或委員會 **必須不同於執行稽核的人**，且要有能力。
- 決定前要確認：資訊足夠；**主要不符合** 的修正與矯正措施已 **審查、接受、查證**；**次要不符合** 的修正與矯正措施 **計畫** 已審查並接受。
- 稽核組要提供：報告、對不符合與措施的意見、確認申請資訊、確認已達成目標、**是否授與驗證的建議**。

| 不符合 | 發證前要求 |
|---|---|
| 主要 | 措施要 **實施並經查證** |
| 次要 | **計畫** 被接受即可，下次稽核查證 |

## 16. 追查稽核（§9.6.2）

追查稽核是 **現場稽核，但不一定是完整系統稽核**。每次至少包括：

- 內部稽核與管理審查
- 前次不符合措施的審查
- **抱怨處理**
- 有效性與目標達成
- 持續改善活動的進展
- 持續的作業管制
- 變更審查
- **標誌使用與驗證引用**

其他追查活動：詢問、審查客戶的宣傳資料或網站、要求文件紀錄。

## 17. 重新驗證（§9.6.3）

- 目的：確認整體管理系統的持續符合性與有效性，以及 **驗證範圍的持續適切性**。
- 要審查過去的追查報告與週期內績效。
- 有 **重大變更**（例如法律變更）時，可能需要第一階段。
- 主要不符合要在 **證書到期前** 實施並確認；做不到就不建議重新驗證，**不得延長效期**。
- 到期前完成重新驗證，新到期日以 **原到期日** 為基礎計算。

## 18. 特別稽核（§9.6.4）

- **擴大範圍**：可與追查稽核一起做。
- **臨時通知稽核**：為調查抱怨、因應變更、跟催暫時終止的客戶。條件要事先讓客戶知道；因為客戶沒機會對稽核組成員提出異議，**指派稽核組要特別小心**。

## 19. 暫時終止、終止、縮減範圍（§9.6.5）

**暫時終止的情況**：持續或嚴重不符合要求；**客戶不讓追查或重新驗證依頻率進行**；客戶自願要求。

- 暫時終止期間，驗證 **暫時無效**。
- 問題在期限內解決就恢復；解決不了就 **終止或縮減範圍**。
- 部分範圍持續或嚴重不符合時，**縮減範圍** 排除該部分。

## 20. 申訴 vs 抱怨（§9.7、9.8）— 易混

| | 申訴（appeal） | 抱怨（complaint） |
|---|---|---|
| 誰提出 | 通常是 **受驗證客戶**，對驗證機構的 **決定** 不服 | 任何人，對驗證機構或已驗證客戶的 **表現** 不滿 |
| 處理人員 | **不同於執行稽核與做驗證決定的人** | 決定由 **未涉及該主題** 的人處理或核准 |
| 是否公開 | — | 與客戶及抱怨者共同決定是否公開及公開程度 |

兩者都：不得差別待遇、要書面化流程、要通知受理、進度、結果與結案。

## 21. 驗證機構自己的管理系統（§10）

兩種選項：**A 一般管理系統要求** 或 **B 依 ISO 9001**。

選項 A 的管理審查輸入包括：內外部稽核、回饋、**公正性維護**、矯正措施、風險措施、先前跟催、目標、變更、**申訴與抱怨**。

## 情境題速判

| 情境 | 正確做法 |
|---|---|
| 客戶要求某位稽核員不要來 | 驗證機構要給客戶異議機會，有效異議就重組 |
| 稽核中發現安全危險 | 組長報告客戶與驗證機構，可能修改計畫或終止 |
| 觀察員在訪談中插話引導 | 稽核組要確保觀察員不干擾 |
| 陪檢員替受訪者回答 | 陪檢員不得影響稽核結果，稽核員應請受訪者本人回答 |
| 客戶在結束會議不同意不符合 | 討論；未解決就記錄並提交驗證機構；不符合仍成立 |
| 客戶問「該怎麼改」 | 不提供特定解決方案，可說明要求的意圖 |
| 技術專家要獨立去訪談某部門 | 不行，技術專家要由稽核員陪同 |
| 驗證機構的子公司想接該客戶的顧問案 | 違反公正性，不得提供顧問 |
| 第二階段開出主要不符合，客戶 7 個月後才完成 | 超過 6 個月，要再做第二階段 |

## 考試陷阱

- 「驗證週期從證書發出日起算」→ 錯，從驗證決定起算。
- 「稽核目標由客戶決定」→ 錯，由驗證機構決定；範圍與準則才與客戶討論。
- 「驗證稽核也是法遵稽核」→ 錯。
- 「第一階段一定要在現場」→ 錯，部分在現場有幫助但非必要；第二階段才必須在現場。
- 「做驗證決定的人可以是稽核組長」→ 錯，要不同於執行稽核的人。
- 「技術專家的時間計入稽核時間」→ 錯。
- 「驗證標誌可印在產品包裝上」→ 錯。
- 「驗證機構可以用顧問公司的稽核員團隊」→ 錯；個別簽約的稽核員可以。
- 「次要不符合需在發證前完成矯正並查證」→ 錯，計畫被接受即可。
