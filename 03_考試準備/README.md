# 03 考試準備

> 考試規則見 [考試指南](../00_課程導覽/考試指南.md)。全部題目與情境都是 **自行原創**，不是課程題庫；考試時禁止使用 AI，這些只供考前複習。

| 檔案 | 用途 | 建議時機 |
|---|---|---|
| [考前速查表](考前速查表.md) | 一頁全課程重點，開卷考可列印 | 考前一週起 |
| [考前衝刺：數字與易混總表](考前衝刺_數字與易混總表.md) | 所有數字題與易混配對 | 考前 1～3 天 |
| [開卷翻書索引與衝刺計畫](開卷翻書索引與衝刺計畫.md) | 題目關鍵字對應標準條次；1 天、3 天讀書計畫；小組分工 | 考前貼標籤 |
| [考試陷阱總整理](考試陷阱總整理.md) | 各筆記「考試陷阱」合併成一頁，錯誤說法 → 正確觀念 | 考前最後一小時 |
| [練習題](練習題.md) | 第一輯，依考試單元 | 讀完觀念筆記後 |
| [練習題 第二輯](練習題_第二輯.md) | 102 題，依課程資源筆記出題，含條款 4 × 生命週期與法規進階題 | 讀完課程資源筆記後 |
| [情境題決策樹與 30 題](情境題決策樹與30題.md) | 考試單元 4、5 的判斷方法與速練 | 考前 2～3 天 |
| [模擬稽核演練：智腕科技第二階段](模擬稽核演練_智腕科技第二階段.md) | 起始會議到跟催的完整演練，15 個停下來想 | 單元 13、14 前後 |
| [中英術語對照](中英術語對照.md) | 開卷翻英文標準時反查；三個最容易翻錯的詞 | 考前貼標籤時 |
| [Anki 字卡](flashcards_anki.tsv) | 139 張，標籤依考試單元 | 通勤零碎時間 |

## 匯入 Anki

Anki → 檔案 → 匯入 → 選 `flashcards_anki.tsv`。檔頭已設定 Tab 分隔、第 3 欄為標籤。可依標籤「考試1」～「考試5」分組複習。
