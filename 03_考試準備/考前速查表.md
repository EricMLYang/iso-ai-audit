## 證據 → 結論
資訊來源 → 抽樣蒐集查證 → **證據** → 對照**準則** → **發現** → 審查 → **結論**

## 19011 §6 流程
6.2 啟動 → 6.3 準備 → 6.4 執行（起始會議…結束會議）→ 6.5 報告 → 6.6 完成 → 6.7 跟催

## 驗證流程（17021-1）
申請審查 → Stage 1（文件、準備度）→ Stage 2（實施有效性）→ 決定 → 證書 3 年 → 每年監督 → 重新驗證

## 方案 vs 計畫
方案：一段期間多次稽核，方案管理者 · 計畫：單次稽核，稽核組長

## 不符合
陳述 = 要求 + 客觀證據 + 不符合描述
主要：影響達成預期結果的能力／系統性 · 次要：偶發、不影響能力
修正 = 處理問題本身 · 矯正措施 = 消除原因防再發 · 有效性驗證 = 一段時間後確認不再發生

## 發現分類
符合 · 良好實作 GP · 改善機會 OFI · 觀察事項 OBS · 不符合 NC（發現不可超出抽樣與證據範圍、不可帶顧問建議）

## 風險證據 7 層次
辨識 → 評估 → 決定處理 → 規劃控制 → 實施控制 → 殘餘風險核准 → 證明有效

## 驗證建議 ≠ 驗證決定
稽核組提建議；決定由未參與稽核的人員獨立作成

## 稽核類型
第一方 內稽 · 第二方 客戶稽供應商 · 第三方 驗證／法規 · 結合＝多套系統 · 聯合＝多個稽核組織

## 驗證 vs 認證
驗證 certification：驗證機構 → 組織 · 認證 accreditation：認證機構 → 驗證機構

## 情境題口訣
只看證據 · 不當顧問 · 有事先報組長 · 歧見寫進報告 · 保密獨立
